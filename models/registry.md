# 모델 레지스트리

> **가중치는 여기에 커밋하지 않는다.** 포인터만 남긴다.
>
> Git LFS도 쓰지 않는다 — GitHub 무료 LFS는 1GB 스토리지/1GB 월 대역폭이라
> 440MB 체크포인트 2~3개로 즉시 초과된다.

## 공개 정책 — 이중용도 통제

| 모델 | 성격 | 공개 |
|---|---|---|
| **1단 탐지기** | 방어 측 | private → **M4에 public** |
| **2단 추론기** | 공격 측(속성 추론) | **비공개 유지** |

탐지기를 잘 만들면 그게 곧 추론기다. 방어 측만 공개한다 ([plan.md §13.5](../docs/plan.md)).

## 등록

| 이름 | 단계 | 베이스 | 방식 | 위치 | 학습일 | 데이터 버전 | 지표 |
|---|---|---|---|---|---|---|---|
| | 1단 | KoELECTRA-base | full FT | | | | |
| | 2단 | Qwen3-4B | QLoRA 4bit | | | | |

**모든 행에 학습일 · 데이터 버전 · 지표를 함께 적는다.** 없으면 10주 뒤에
그 체크포인트가 무엇이었는지 복원할 수 없다.

## 추론 요구사항 (제품 기준)

| 모델 | 4bit 추론 VRAM | 대상 |
|---|---|---|
| Qwen3-4B | ~3GB | 일반 노트북 |
| ~~Qwen3-8B~~ | ~6GB | **후보 제외** — 일반 노트북 기준을 벗어난다 |

**학습 VRAM과 추론 VRAM은 다른 문제다.** 학습 데이터가 전량 합성이라
학습은 클라우드에서 해도 되고, 진짜 제약은 **사용자 PC에서의 추론**이다.
