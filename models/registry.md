### 1단 koelectra-v1 — W5 등록 (2026-09-17)

- 기존 LR 5e-5 실행의 epoch 1~10을 동일 내부 eval·후처리로 비교했으며,
  epoch 10이 partial F1 0.4839와 exact F1 0.4194 모두 최고였다.
  비교는 test 공개 이후 내부 eval에서만 수행했고, 다른 epoch를 test로 재비교하지 않았다.
- 학습: reviewed 정본 311편·464스팬 → 801 BIO 창, persona holdout
  train 706 / eval 95창. full FT, 10 epochs, batch 16, LR 5e-5,
  o_weight 0.02, fp16, seed 20260911. 이 등록 모델은 기존 비결정적 실행이며
  별도 deterministic A·B 모델(F1 0.4516)과 혼동하지 않는다.
- 후처리: 긴 스팬 우선 겹침 해소 + 평균 토큰 확률/창별 평균 점수 임계값 0.7.
  0.7은 내부 eval에서 선정한 잠정 운용값이며 test상 최적값을 입증하지 않는다.
- test: 공식 255편에서 팀 승인대로 기존 IAA 16편을 평가시에만 제외한
  239편·358스팬. partial TP 111 / FP 286 / FN 247, exact TP 61 / FP 336 / FN 297.
  현재 split·BIO의 글 ID 누수는 0건이나 인물 66명은 겹친다.
  잡담은 blind가 아닌 검수본이고, 기존 체크포인트에는 당시 학습 입력 해시가 없다.
- CPU: Ryzen 5 9600X, 4스레드, 입력별 워밍업 5회·반복 30회.
  합성 39/195/780자(1/1/2창)의 p95는 24.07/67.60/276.31ms.
  토큰화·추론·후처리·계약 검증 포함, 로딩 2.81초 제외.
  실제 코퍼스 전체 지연 또는 향후 등급·주체 판정 비용의 달성을 보장하지 않는다.
- 모델은 경계·유형만 예측한다. `level=implicit`·`subject=self`는 호환용
  고정값이며 의미 판정이 아니다. E 인계 시 이 제한을 함께 전달한다.
- 가중치 SHA-256: `3c2d9867e672fdfd5542d51eb0f0cf449266ed58c63ad582511047f4549530b5`.
  경로는 로컬 포인터이며 Git clone으로 가중치가 내려오지 않는다.
- 상세 비교표·평가 명령·측정 한계: [exp06 README](../experiments/exp06-finetune/README.md).

이는 W5 초기 모델 등록이며 최종 제품 성능 목표를 달성했다는 의미가 아니다.

### W7 성능 리포트 — 운용 모델 교체 전 비교 (2026-10-02)

아래는 **등록 모델 교체가 아닌 실험 결과**다. 현재 `koelectra-v1` 등록 행과
E에 전달한 체크포인트는 그대로 유지한다. 검수+교사 후보의 운용 채택과
체크포인트 인계는 W8 [#293](../../../issues/293) 교사 순환 점검을 함께 보고 결정한다.
[#293](../../../issues/293)의 민감도 입력은 **기존 v1 단독·v1+규칙**으로
한정한다. 새 교사 후보는 그 분석의 190편 중 168편을 학습에서 보았으므로
교사 순환 점검의 대체 예측 모델로 쓰지 않는다.
측정 데이터는 `corpus-v0 p2.3`, 베이스는
`monologg/koelectra-base-v3-discriminator`다. 공식 test 255편 중 기존
IAA 16편을 제외한 **239편·358스팬**을 임계값 0.7로 채점했다.
`test.jsonl` SHA-256은
`9662a167f530f47318da2bd37a8401988ee74555393d6cd377fa84dfe8a886ad`다.
주 지표는 type 일치·IoU ≥ 0.5·탐욕 1:1 partial, exact는 참고치다.
모델은 level을 예측하지 않으므로 명시 F1은 전체 정밀도를 공유하는
[#276](../../../issues/276)의 **proxy** 산식이다.

#### 학습 글의 동일 표기 출현 여부별 재현율

[#294](../../../pull/294) 리뷰 요청에 따라 저장된 test 예측을 다시 읽어 공식 partial
매칭의 **같은 TP**를 정답별로 나눴다. 출현 기준은 실제 BIO 학습 글의
`(type, NFC 원문 표기)`이며 앞뒤 공백만 제거하고 조사는 떼지 않는다.
`시누이`·`학원가`처럼 낱말 일부가 조사와 같은 글자인 경우를 잘못 자르지 않기 위해서다.
모든 test 글·내부 eval 인물의 글은 출현 목록에서 제외한다.
아래 ‘못 봄’은 **이 표기 비교에서만** 못 봤다는 뜻이지, 새로운 사실이나
처음 보는 인물이라는 뜻이 아니다.

| 학습 후보 · 정답 범위 | 학습 글에 같은 표기 있음: TP/정답 · 재현율 | 없음: TP/정답 · 재현율 |
|---|---:|---:|
| 새 검수만 · 명시 | 11/12 · 0.9167 | 22/100 · 0.2200 |
| 새 검수만 · 전체 | 54/65 · 0.8308 | 88/293 · 0.3003 |
| 새 검수+교사 · 명시 | **26/32 · 0.8125** | **55/80 · 0.6875** |
| 새 검수+교사 · 전체 | 82/106 · 0.7736 | 129/252 · 0.5119 |

같은 인물의 학습 글로만 좁히면 교사 후보의 명시는 12/13(0.9231) 대
69/99(0.6970), 전체는 49/57(0.8596) 대 162/301(0.5382)이다.
PM의 원문 일치 간이 집계(교사 후보 명시 32/112 · 전체 110/358)와
스크립트의 명시는 같지만 전체 출현 수는 106/358로 4개 다르다.
이 스크립트는 실제 BIO 학습 글·같은 유형·정확한 NFC 원문 기준이며,
서로 다른 집계의 수치를 섞지 않는다.

위 표의 ‘없음’ 묶음은 모델마다 다르므로, **교사 학습 글에도 같은 원문 표기가
없는 명시 정답 80개**를 고정해 두 모델을 나란히 비교했다.
새 검수만 모델은 **15/80(0.1875)**, 새 검수+교사 모델은
**55/80(0.6875)**를 맞혔다. 동일 표기 암기만으로는 이 차이를 설명할 수
없지만, 비슷한 문구나 같은 인물의 사실을 학습한 효과까지 배제하지는 못한다.

| 모델 | 모드 | 시간 | 출력 토큰 | 결과 |
|---|---|---|---|---|

⚠️ **표본 1건이다. 크기 결정의 근거로 쓰기에는 부족하다.** 다만 두 가지는
지금 적어둘 값이 있다.

1. **`think:false` 옵션이 안 먹는다.** 프롬프트에 `/no_think` 를 붙여야 하고,
   그러면 이번 표본에서는 두 모델 다 형식을 못 지켰다. **사고 토큰을 빼는 것이
   공짜가 아니다** — 2단 프롬프트 설계에서 토큰 예산을 그만큼 잡아야 한다.
2. **1.7B 가 근거 인용을 더 좁게 했다.** 4B 는 본문 전체를 evidence 로 넣었고
   1.7B 는 `"서른여덟."` 한 어절만 넣었다. 우리 2단 출력은 **근거 스팬**을
   요구하므로 이 차이가 그대로 지표에 걸린다. 크기가 크다고 유리한 축이 아니다.

**W3 초 크기 결정(1.7B/4B)에서 이 두 가지를 같은 프롬프트로 n≥20 재측정한다.**

**갈린 자리는 「말을 아끼는 능력」이다.** 단서가 있을 때 발언하는 것은 98.3% 로 완전 동률이고,
차이는 전부 **단서가 없을 때 기권하는가**와 **남의 정보를 근거로 쓰지 않는가**에서 나왔다.

**`think=false` 가 이번에는 먹었다.** W2 에 안 먹은 것은 `/no_think` 프롬프트 토큰 쪽이었고,
API 의 `think` 필드는 정상 동작한다. 그리고 `format` 강제로 **형식 붕괴가 사라졌다**
— W2 에 두 모델 다 형식을 못 지키던 문제가 구조 강제만으로 해결됐다(구조 35/35 · 양쪽).

### 한계 (W4 설계서에 같이 적는다)

- **prompt-only 스팬 판정에 한정된 선택이다.** 전체 `Stage2Output`·글 간 결합·k 값·QLoRA 후 성능은 재지 않았다
- **`D-stage2.md` §4 의 「7속성 중 5개 적중」을 입증한 것이 아니다.** 그 기준은 **값 적중**이고
  계약 `Finding` 에는 속성 값 필드가 없다. 이 측정의 ①은 **특정 가능성 판정**이다
- **선행 PoC 의 R1~R5 7/7 · R6 6/7 과 직접 비교 불가.** R1~R6 원 조건이 저장소에 없다
- n=35 · 단일 seed · 1회 실행. `sex` 는 표본이 5칸뿐이다

### ⚠️ 여기서 나온 W4 학습 1순위

**두 모델 다 함정을 근거로 쓴다** (4B 도 34명 중 22명). `subject: other` 스팬을 본인 속성의
