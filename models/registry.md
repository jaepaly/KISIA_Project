# 모델 레지스트리

> **가중치는 여기에 커밋하지 않는다.** 포인터만 남긴다.
>
> Git LFS도 쓰지 않는다 — GitHub 무료 LFS는 1GB 스토리지/1GB 월 대역폭이라
> 440MB 체크포인트 2~3개로 즉시 초과된다.

## 공개 정책 — 이중용도 통제

| 모델 | 성격 | 공개 |
|---|---|---|
| **1단 탐지기** | 방어 측 | private → **M4에 public** |
| **2단 추론기** | 공격 측(속성 추론) | **비공개 유지** |

탐지기를 잘 만들면 그게 곧 추론기다. 방어 측만 공개한다 ([plan.md §13.5](../docs/plan.md)).

**v1 로 되돌리기** — 코드 한 커밋 되돌림 + 어댑터 경로:

1. 서버를 멈춘다 (모델은 프로세스에 한 번 올라가 캐시된다)
2. `infer.py` 의 `MODEL_VERSION` → `qwen3-4b-qlora-v1` · `_DEFAULT_ADAPTER` → `results/adapter` · `MODEL_MAX_SPANS` 24 · `MODEL_MAX_SPANS_PER_TYPE` 6 · `Stage2Model` 기본 system → `SYSTEM_V1` · `build_user_prompt(cap=True)` 에서 빈 글 제외 줄 삭제 (= 이 교체 커밋 `git revert`)
3. `STAGE2_ADAPTER_DIR` 을 v1 어댑터 폴더로 바꾸거나, 지우고 `results/adapter` 에 v1 을 둔다. v1 어댑터 SHA-256 `1053e7adcc77d1863e0789978b468d29d92930dc9c26a84a0a29e7fbc99a6a4b` 확인 (보관본: D 로컬 저장소 밖)
4. 출력 상한 수정(#346)은 v1 에도 그대로 둔다 — exp22b v1 수치가 그 상태다
5. 서버를 다시 켜고 분석 결과 provenance 의 `model_version` 이 `qwen3-4b-qlora-v1` 인지 본다

**2026-10-09 운용 결정**: B·D는 [#322](../../../issues/322)에서 **기준선 v2 유지**를
확정했다. v1 행은 과거 등록·인계 이력으로 보존한다. 앱 기본값 변경은 D의 별도 PR
(E 리뷰), v2 체크포인트의 E 통합 검증·리허설 PC 전달은 별도 작업이다.

#### 학습 글의 동일 표기 출현 여부별 재현율

[#294](../../../pull/294) 리뷰 요청에 따라 저장된 test 예측을 다시 읽어 공식 partial
매칭의 **같은 TP**를 정답별로 나눴다. 출현 기준은 실제 BIO 학습 글의
`(type, NFC 원문 표기)`이며 앞뒤 공백만 제거하고 조사는 떼지 않는다.
`시누이`·`학원가`처럼 낱말 일부가 조사와 같은 글자인 경우를 잘못 자르지 않기 위해서다.
모든 test 글·내부 eval 인물의 글은 출현 목록에서 제외한다.
아래 ‘못 봄’은 **이 표기 비교에서만** 못 봤다는 뜻이지, 새로운 사실이나
처음 보는 인물이라는 뜻이 아니다.

| 학습 후보 · 정답 범위 | 학습 글에 같은 표기 있음: TP/정답 · 재현율 | 없음: TP/정답 · 재현율 |
|---|---:|---:|
| 새 검수만 · 명시 | 11/12 · 0.9167 | 22/100 · 0.2200 |
| 새 검수만 · 전체 | 54/65 · 0.8308 | 88/293 · 0.3003 |
| 새 검수+교사 · 명시 | **26/32 · 0.8125** | **55/80 · 0.6875** |
| 새 검수+교사 · 전체 | 82/106 · 0.7736 | 129/252 · 0.5119 |

같은 인물의 학습 글로만 좁히면 교사 후보의 명시는 12/13(0.9231) 대
69/99(0.6970), 전체는 49/57(0.8596) 대 162/301(0.5382)이다.
PM의 원문 일치 간이 집계(교사 후보 명시 32/112 · 전체 110/358)와
스크립트의 명시는 같지만 전체 출현 수는 106/358로 4개 다르다.
이 스크립트는 실제 BIO 학습 글·같은 유형·정확한 NFC 원문 기준이며,
서로 다른 집계의 수치를 섞지 않는다.

위 표의 ‘없음’ 묶음은 모델마다 다르므로, **교사 학습 글에도 같은 원문 표기가
없는 명시 정답 80개**를 고정해 두 모델을 나란히 비교했다.
새 검수만 모델은 **15/80(0.1875)**, 새 검수+교사 모델은
**55/80(0.6875)**를 맞혔다. 동일 표기 암기만으로는 이 차이를 설명할 수
없지만, 비슷한 문구나 같은 인물의 사실을 학습한 효과까지 배제하지는 못한다.

### ⚠️ 여기서 나온 W4 학습 1순위

**두 모델 다 함정을 근거로 쓴다** (4B 도 34명 중 22명). `subject: other` 스팬을 본인 속성의
근거로 쓰는 것은 계약이 금지한 동작이고, **기존 도구와 갈리는 지점이 정확히 여기다.**
프롬프트만으로는 안 된다 — QLoRA 학습의 1순위 목표로 둔다.
