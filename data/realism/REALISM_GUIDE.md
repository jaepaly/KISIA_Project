# 페르소나 리얼리티 가이드

내일 페르소나 재정비 시 지침. 팀원이 수집한 **실제 네이버 블로그 글(대학생 종강 일기)** 의 문체·구조를 **톤 참조용으로만** 분석해 도출.
목표: "단서를 심은 티"를 없애고, 실제 사람 글처럼 **노이즈 속에 무심코 단서가 새어나오게**.

> ⚠️ 윤리 원칙: 실제 타인의 공개 글은 **톤·구조 참조까지만**. 그 글 자체를 데이터셋으로 저장·추론에 사용하지 않는다(동의 없는 개인정보 처리 + 자기모순 회피). 아래에도 실존 인물의 식별 정보(실명·구체 학교·지명)는 옮기지 않고 일반화만 기록. 데이터셋은 **합성 페르소나만**, 실인물 검증은 **팀원 본인 동의 데이터만**.

## 실제 글이 위협 모델의 증거인 이유

한 대학생의 종강 일기(잡담·음식·덕질 위주)에서 본인 학교·학과를 **한 번도 직접 안 썼는데도** 다음이 종합 추론됨(구체 식별정보는 여기 옮기지 않음):
- 특정 어학 전공 2학년 (해당 어학 고급 자격증 보유인데도 수업이 힘들다는 토로 + 과다 학점 + 전공 멘토링 + "2-1학기")
- 학교가 좁혀짐 (동네 시장 이름 + 유명 아이돌이 온 축제 + 어학 특성화 → 서울 소재 특정 대학군)
- 알바·직함, 친구 실명 여럿, 취향(주류 종류·드라마 취향)
→ **노이즈 80% + 희소 단서 + 종합 추론** = 우리가 합성으로 재현할 데이터의 모습.

## 문체 특성 (반영할 것)

- **의식의 흐름**: 한 글에서 종강→축제→음식→술→드라마로 주제 폭발적 전환. 통일성 없음.
- **문장부호 남발**: 쉼표를 말줄임처럼(",,,"), 느낌표 폭발("종강!!!!!!!"), "…"
- **오타·축약**: 출긘(출근)·퇴긘·머금(먹음)·마쉿(맛있)·왤케·조아·기엽어·햇어요
- **구어체 혼용**: ~했어요 / ~했다네요 / ~함 / ~임 뒤섞임
- **이모티콘**: 🥹 😽 등 드문드문
- **밈·은어**: 손민수(따라 사기)·정병 발사·차력쇼·에바·불펌
- **자기비하 유머**: "멍청소비" "뇌를 빼고 살" "진짜 바보 같아"
- **감정 과잉**: 힘들어/토나와/좋아서 토나옴
- **괄호 자기부연**: "오랑이밥(집에서 포케 해먹었다는 뜻)"

## 구조 특성

- 사진 캡션식 **짧은 단락**을 일주일~한 달 **몰아쓰기**("이거 목요일이네?", "토요일일요일")
- 사진 전제("저거", "이 옷", "○○사진 불펌")
- **덕질/취미 콘텐츠가 분량의 절반 이상** — 신상 무관 순수 노이즈(드라마 배우 얘기 등)
- 극도로 개인적·독백적
- **글 유형은 여러 갈래**: ① 순수 일상 파편(종강 일기형) ② 주제 후기·정보 공유글(이직 후기·제품 리뷰·여행기형 — 번호·목록 구조에 정보성이라 오히려 업계·전문성·소비수준을 강하게 노출). 정서도 감성·자기비하 ↔ 자조·분노·냉소로 갈림. 한 페르소나 안에도 여러 유형이 섞임.

## 단서 흘리는 법 (핵심)

절대 프로필을 직접 쓰지 않는다. 대신:
- **자랑 속에**: "○○어 고급 자격증 있는데도 이 수업 힘들어"
- **불평 속에**: "동네 시장 통로 좁아서 나오다 병 깸"(동네 노출)
- **무심코 언급**: "학교에 (유명 아이돌)가 왔어요"(축제→학교 좁혀짐)
- **일상 나열**: 알바·조교·멘토링을 그냥 툭
- **리스트로 흘리기**: 지원/방문/구매 목록이 신상 노출 — 지원 회사군→업계·직무, 면접·방문 장소들→거주 지역, 산 물건·먹은 것→소득·취향
- **타인 발화 인용으로**: "면접관이 내 학교 어떤 학교냐 물어봄(지방대라 그런듯)" — 남의 말을 옮기며 자기 학력·나이를 무심코
- **경력·연차 나열로 나이 역산**: "인턴 2년 + 정규직 3년 5개월" → 직접 나이 안 쓰고 나이 드러남
- **지도/장소 임베드(네이버 블로그 특유)**: 맛집·학원·카페의 **정확한 주소가 그대로 박제**됨. 장소의 성격을 구분해 교집합으로 거주지 특정 — 학원·병원·헬스장은 집 근처, 맛집·핫플은 나들이(활동 반경). 여러 장소 종합해야 거주지가 나옴.
- **교통 노선번호**: 셔틀·마을버스 노선(예: "분당3호/판교1호")으로 생활권 노출
- **소비 내역**: 가격·브랜드(필라테스 월 회비, 특정 프랜차이즈, 명품/취미 장비)로 소득 수준
- **가족 경조사**: 조부모 팔순·자녀 돌잔치 등으로 본인 세대·나이 역산
- **자영업 블로그 = 홍보+일상 결합**: 프로필·글 속 상호·업종·지역·홍보 링크가 신원에 직결(자영업자는 블로그가 사업 채널이라 개인 블로그 중 노출 최대)
- **셰어런팅**: 자녀 이름·개월수·어린이집·얼굴·일과 공개 → 미성년 제3자 정보 + "N개월 때 O월 입학"으로 자녀 생년월 역산
- **아이디에 이름+연도**: 블로그/계정 아이디(예: 이름+출생연도)가 실명·나이 단서
- **대량 활동 이력의 통계적 노출** ⭐: 개별 글(맛집 리뷰 등)은 무해해도, 수백~수천 개의 방문 지역·시간·소비를 집계하면 특정 자치구·상권 축이 드러나 생활권이 통계적으로 특정됨(누적 노출 H3의 실물). → 합성 데이터도 여러 글의 지역 분포가 집계 시 생활권을 드러내도록 설계

## 페르소나 생성 체크리스트

- [ ] 글의 70~80%가 신상과 무관(맛집·제품 후기·드라마·펌·넋두리·날씨)
- [ ] 핵심 단서(거주지·학교·직장·나이)는 직접 명시 0, 종합해야만 도출
- [ ] 단서는 자랑/불평/무심코 속에 흩뿌림, 여러 글에 분산
- [ ] 문체 리얼리티(오타·쉼표·밈·이모티콘·자기비하) 반영
- [ ] 시간축: 작성 연도 × 생애이벤트로 나이·학년 역산 가능하게
- [ ] 계정 메타(아이디·닉네임·작성 시각·활동 카페/카테고리)도 단서
- [ ] 각 단서에 명시성 등급(explicit/implicit/inferential) 라벨
- [ ] (윤리) 실존 인물·상호·지명을 그대로 쓰지 않는다 — 전부 가상으로 창작
- [ ] **페르소나마다 톤이 다르다** (아래 참조) — 획일적 문체 금지

## 페르소나별 톤 차별화 (획일화 금지)

위 "문체 특성"은 20대 대학생 톤의 한 예시일 뿐. **페르소나마다 목소리가 완전히 달라야** 한다(안 그러면 "전부 똑같은 AI"라는 또 다른 가짜). 각 페르소나에 고유 voice 프로필 부여:

| 축 | 예시 편차 |
|---|---|
| 종결어미 | ~함/~임(20대) · ~해요/~네요(30~40대) · ~습니다(중년) · 초성체(10대) |
| 문장부호 | 쉼표 남발",,,"(2030) · 마침표·짧게(40대 남) · 물결~느낌표(주부) · "^^ . ."(중년) |
| 이모티콘 | ㅋㅋㅠ(2030) · ㅎㅎ~(주부) · ^^(중년) · 급식 이모지(10대) · 거의 없음(40대 남·전문직) |
| 소재 | 아이돌·게임(10대) · 덕질·자취·맛집(20대) · 육아 정보(30대 맘) · 차·등산·부동산·물가(40대 남) · 건강·손주·여행(50~60대) · 기술(전문직) |
| 맞춤법 | 의도적 축약·오타(2030) · 표준(30~40대) · 띄어쓰기 특이(중년) |
| 글 길이·구조 | 짧고 파편적(10~20대) · 정보성 길게(30대 맘) · 짧고 건조(40대 남) · 사진+짧은 설명(중년) |

**세대·유형 대비 예시("점심 먹었다")**:
- 10대: `급식 존맛탱인데 매점도 감ㅋㅋ ㄹㅇ`
- 20대 자취: `회사 앞 국밥,,,사장님이 나 알아보심ㅋㅋ`
- 30대 워킹맘: `동료들이랑 파스타 먹었어요~ 이런 여유 얼마만인지 ㅎㅎ`
- 40대 남: `회사앞 백반 8천원. 물가 올랐네요.`
- 50~60대: `아들내외랑 갈비집 다녀왔습니다 ^^ 손주가 잘먹던지 . .`
- 전문직: `김밥 때우고 계속 디버깅. 이 버그 3일째`

→ 페르소나 세트 설계 시 연령·성별·직업뿐 아니라 **voice(종결어미·부호·이모티콘·소재·맞춤법·길이)를 각자 다르게 명시**하고, 계정 메타에도 기록.
