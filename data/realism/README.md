## 쓰는 법

**① 생성 프롬프트의 스타일 지시로.** 카드 특징을 그대로 넣는다.

```
아래 문체로 써라:
- 짧고 끊는 문장. 평균 15자, 최소 4자 ~ 최대 40자
- 종결은 "~함" "~했음". 존댓말 안 씀
- 오타를 두세 개 섞어라 ("됬다" "함니다" 같은 자모·띄어쓰기 오류)
- 이모지 대신 "ㅎㅎ"
```

**② 검수 기준으로.** 만든 글을 카드와 대조한다. 절차는 [A-data.md §3](../../docs/roles/A-data.md).

---

## ⚠️ 원칙

- 실제 공개 글은 **톤·구조 참조까지만.** 원문을 저장하거나 인용하지 않는다
- 식별 정보(실명·정확 주소·학교·상호)는 **괄호 일반화**해서 적는다 — `(어학) 자격증`, `(동네) 시장`
- 이 카드는 **톤 참조 전용**이다. 실험 데이터셋으로 쓰지 않는다 — 데이터는 100% 창작

## 커버리지 — 카드를 추가할 때 여기부터 본다

### 현재 (10장)

| 카드 | 연령·성별 | 직업/신분 | 지역 |
|---|---|---|---|
| S1 | 20대 여 | 대학생 (어학) | 수도권 |
| S2 | 20대후반~30초 | 경력직 이직 | 수도권 |
| S3 | 20대 초 여 | 대학생 | 수도권 |
| S4 | 20대 초 여 | 대학생 (심리) | 수도권 |
| S5 | 30대 여 | 워킹맘·자영업 | 수도권 |
| S6 | 미상 | 리뷰 블로거 (대량) | 수도권 |
| S7 | 미상 | 해외 거주·취미 | 해외(중국) |
| S8 | 20대 | 워홀러 | 해외(호주) |
| S9 | 30대 여 | 상류 육아맘 | 수도권 |
| S10 | 미상 | 지방 리뷰 블로거 | 경남 |

### 비어 있는 축

| 축 | 없는 것 | 왜 필요한가 |
|---|---|---|
| **연령** | **40 · 50 · 60대 전부** | 선행 페르소나 R1(40대)·R4(60대)를 받칠 카드가 없다 |
| **성별** | **남성이 사실상 없음** | 코퍼스가 여성 문체로 쏠린다 |
| **직업** | 현장직 · 기술직 · 은퇴자 · 농어업 | 학생·사무직·육아·리뷰어에 몰림 |
| **지역** | 비수도권 (S10만) | 지역 단서의 다양성 |
| **플랫폼 톤** | 커뮤니티 · 단문 SNS | 블로그 위주 |

### 목표

카드는 **톤 원형**이다. 같은 카드에서도 `voice` 파라미터(종결어미·이모지 빈도·문장 길이·오타율)를 달리하면 인물이 갈리므로, 무한정 늘릴 필요는 없다. **축을 채우는 것이 목표다.**

| 시점 | 카드 수 | 채울 축 |
|---|---|---|
| 현재 | 10장 | — |
| **W2** | **+3~4장** | 40대 남성 · 60대 · 현장직/기술직 |
| W3 | +5~8장 (총 18~20) | 50대 · 비수도권 · 은퇴자 · 자영업 · 커뮤니티 톤 |
| 이후 | 필요 시 | 코퍼스가 늘 때마다 축 점검 |

> **왜 늘려야 하나.** 최종 인물이 100~330명인데 카드가 10장이면 **1장당 10~33명을 재사용**하게 된다. 같은 카드에서 나온 인물은 문체가 비슷해지고, 그러면 분포 검증에서 어휘 다양성이 낮게 나오고, **모델이 내용이 아니라 문체를 외운다.**

카드 1장은 **20~30분**이면 만든다. [HOW-TO.md](HOW-TO.md) 참조.
