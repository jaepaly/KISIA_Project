# S8 — 워킹홀리데이 / 해외 단기 체류자

> 비식별 분석 카드. 원본 미저장(스크래치패드에서만 분석). blogId·URL·구체 지명 마스킹.

## 화자 유형
20대 한국인, 해외(호주) 워킹홀리데이/단기 체류, 여행·디지털노마드 지향

## 톤·문체
- 20대 인터넷 밈·구어: "쥑인다", "잼섰서요", "오지게", "무체력인 나,,"
- 감탄·자조 섞인 여행기, 이모지(🇦🇺), 짧은 줄바꿈
- 솔직·즉흥적 서술

## 구조
- 주차별 "N주차 적응기" 형식(해외 살이 연재)
- 여행지·현지 생활(플랫메이트·현지 은행·송금) 기록

## 단서가 새어나온 방식
- **거주국**: 현지 지명(대도시·해변·동물원) + "플랫메이트" + **재외국민투표·해외송금** → 해외 체류 확정 [explicit]
- **나이**: 워홀 + 밈 말투 + "무체력" 자조 → 20대 [inferential]
- **체류 성격**: 단기(워홀), 디지털노마드 동경 → 생애 단계

## 역추론되는 신상 (일반화)
20대 한국인 + 해외(호주) 워홀·단기 체류 + 대도시(시드니) + 여행 지향 → 거주국·도시·생애단계로 좁혀짐
