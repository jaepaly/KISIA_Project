# S3 — 대학 여름방학 브이로그

> 비식별 분석 카드. 원문 미저장. 톤 참조 전용.

## 화자 유형
20대 초 여대생(삼수 출신), 경기 광주·분당권 거주, 중상위 가정

## 톤·문체
- **날짜별 일기**(6.12, 7.3, 7.5…) + 사진 캡션
- 애교체 + 자기비하, 이모티콘 폭발(🥺 ^◡^ 🥲)
- 밈: 잇츠미·무지성·ㅂㅌ·센세·홀라당

## 구조
날짜 헤더 + 사건별 사진/캡션, 브이로그형

## 단서가 새어나온 방식 (⭐ 지도 임베드)
- **네이버 지도/장소 임베드로 정확 주소 박제**: 운전학원·맛집 주소가 그대로 노출
- **장소 성격 구분**: 학원·병원·헬스장(집 근처) vs 맛집·핫플(나들이) → 교집합으로 거주지 특정
- **교통 노선번호**("분당3호/판교1호" 셔틀) → 생활권
- **소비**(필라테스 월 회비·프랜차이즈)→경제, **가족 경조사**(외조부 팔순)→본인 세대·나이

## 역추론되는 신상 (일반화)
삼수+대학 2학년 → 만 21~22세, 여성, 경기 광주·분당권(학원+셔틀 종합), 중상위 → 조합으로 특정

## 이 샘플에서 배울 것
⭐ **지도/장소 임베드로 정확 주소 노출**(우리 데이터에 반영할 킬러 요소) / 노선번호·소비·경조사 단서 / 날짜별 브이로그 포맷
