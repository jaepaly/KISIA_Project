## ⚠️ 윤리 원칙 (중요)
- 실제 글의 **원문을 그대로 저장하지 않는다.** 친구 실명·정확 주소·학교·특정 공연/브랜드 등 식별 정보는 마스킹·일반화.
- 톤의 생생함은 특징적 표현(오타·밈 패턴 등)으로만 남기고, 문장 단위 원문 발췌는 지양.
- 이 카드들은 **톤 참조 전용**. 실험 데이터셋으로 쓰지 않는다(데이터는 100% 창작).
- 근거: 공개돼도 개인정보 + 제3자(친구) 정보 포함 + "방어 도구가 침해를 저지르는" 자기모순 회피.
