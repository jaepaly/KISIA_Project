# 데이터

> 개발·학습 코퍼스는 **전량 합성**이다. 실존 인물 0.
> 근거와 5중 방어 논리는 [plan.md §6](../docs/plan.md).

## 구조

| 경로 | 내용 | 커밋 |
|---|---|---|
| `corpus/v1/` | 합성 코퍼스 (인물별 글) | ○ |
| `gold/labeled/` | 검수된 골드셋 스팬 | ○ |
| `gold/blind200/` | **blind annotation 200스팬** — 교사 라벨 품질 측정용 | ○ |
| `negative/` | 네거티브 컨트롤 (신호 없는 일상글) | ○ |
| `dict/` | 행정구역 계층·인구 사전 — **C와 D 공동 소유** | ○ |
| `interim/` | 중간 산출물 | 선택 |
| `raw/` | — | **✗ 절대 금지** |
| `consented/` | M4 동의 실데이터 | **✗ 절대 금지** |

## 버전 관리

코퍼스는 **jsonl 스냅샷 + 버전 태그**로 관리한다. `v1` 이 W4에 동결되면
그 이후 변경은 `v1.1` 로 별도 기록한다 — B·D가 학습을 시작한 뒤 데이터가
바뀌면 그때까지의 실험 결과가 전부 무효가 된다.

## 라이선스

외부 코퍼스를 쓸 때는 **이용 조건을 먼저 확인하고 출처를 기록한다.**
대회 참가용처럼 재배포·상업적 이용이 제한된 데이터를 쓰면
**모델 가중치와 벤치마크를 공개할 수 없게 된다.**

| 출처 | 용도 | 라이선스 | 확인일 |
|---|---|---|---|
| (예) KLUE-NER | 명시 PII 보강층 | CC BY-SA 4.0 | |

## M4 동의 데이터 취급

- 서면 동의서 (목적·범위·보관기간·파기 방법·철회권 명시)
- **로컬 전용 처리. 외부 전송 0**
- 분석 종료 즉시 원본·중간산출물 전부 파기
- 발표는 **익명·집계만**
