# 12주 실행 로드맵

> 이 문서가 **2주차 수행계획서 「주차별 수행 계획」과 「담당기간」 칸의 원본**이다.
> 여기 적힌 항목 수가 **8주차 진행률(%)의 분모**이고, 「최종 목표」가 **10주차 달성도 판정의 기준**이 된다.
> 계획서 본문은 [plan.md](plan.md) §8, 역할 정의는 [README](../README.md) 「팀 역할」 참조.

**전제**: 원 계획 4개월(≈17.4주) → **12주**. 공휴일 포함 **근무일 54일**.
**압축률**: M1 −30% / M2 −7% / **M3 −53%** 🔴 / M4 −30%.

⚠️ 주차 기산일은 협회 공지로 확정해야 한다 — 아래 날짜는 **[추정]**이다.

## 1. 단계 경계를 정한 근거

역산 두 개가 모든 것을 결정한다.

| 제약 | 귀결 |
|---|---|
| 8주차 중간점검 양식이 「현재 성능 또는 결과 — 수치·표·그래프」를 **강제** | **M2는 W7 말에 끝나야 한다.** 제출 시점에 이미 측정된 수치가 있어야 하기 때문 |
| 10주차 개발결과정리서가 **최종 성능표**를 요구 | **W9 말이 개발 동결(feature freeze)** |

→ M1 = W1~W3 / M2 = W4~W7 / **M3 = W8~W9** / M4 = W10~W12.

**부채는 M3에 몰린다.** 완화책 3가지: ① 통합을 W8 → **W5로 조기 착수** ② ⑦ 가상 SNS를 **W3~W6에 분산** ③ 아래 스코프 컷.

## 4. 가상 SNS 플랫폼 (⑦) — 주차 배치

플랫폼 계층과 분석 계층은 분리한다([plan.md §4](plan.md)). 이 분리가 §2 자기모순 논거의 성립 조건이다.

| 주차 | 산출 | 담당 |
|---|---|---|
| W3 | **v0 골격** — 글 작성·목록·본문 조회, 프로필 | E |
| W4 | 합성 코퍼스 → SNS **자동 시딩 스크립트** | E · A |
| W5 | 분석 웹앱 3화면 연결 = **통합 조기 착수** · **수동 업로드 경로** | E |
| W6 | **활동 메타 필드** — 닉네임 · 위치태그 · 작성시각 | E |
| W9 | **에디터 실시간 경고** (작성 화면 연동) | E · D |
| W10 | 데모 시나리오 확정 + **시연 영상 녹화** | E |

**활동 메타를 반드시 넣는 이유**: 선행 PoC 실측에서 조치 3종 중 **활동 메타 관리가 위험도 감소 폭 1위**였다(글 리라이트보다 효율이 높았다). 이 필드가 없으면 서비스의 핵심 메시지를 화면에서 보여줄 수 없다.

## 5. 게이트 — 지표 3계층과 갱신 경로

지표를 1주차에 최대치로 선언하면 같은 결과물이 10주차에 "미달"이 된다. 3계층 + 갱신 경로를 미리 선언한다.

| 게이트 | 시점 | 내용 |
|---|---|---|
| **G1 선언** | W1 주제선정서 | [필수]/[목표]/[도전] 3계층 + 갱신 경로 문장 |
| **G2 조정** | W4 설계서 | M1 실측 반영, **멘토 승인 하에 1회 갱신** |
| **G3 확정** | W8 「계획 대비 변경사항」 | 최종 확정. 이후 변경 시 사유 필수 |

```
[필수] 미달 시 프로젝트 실패
  · 스팬 탐지 F1(명시) ≥ 0.80
  · 글 1건 로컬 탐지 지연 < 300ms (CPU)
  · 조치 3단계 적용 시 재식별 위험도 유의미 하락 (선행 PoC −54~61% 수준 재현)

[목표] M1 베이스라인 측정 후 확정
  · 스팬 탐지 F1(암묵) : M1 IAA 측정치의 80% 이상
  · 위험도 상관 Spearman ≥ 0.7 (단위: 글 또는 윈도우)
  · Qwen3 vs 외부 LLM 속성 적중 일치율 ≥ 0.8
  · 기존 도구(Presidio·korean-pii) 대비 추가 탐지율 > 0

[도전] 달성 시 가점
  · Triage LLM 토큰 70%+ 절감 (재현율 ≥ 0.9 유지)
  · 적대적 회피 후 재현율 하락 ≤ 15%p
```

**중단 기준(kill criterion)**: W3에 측정하는 **「기존 도구 대비 추가 탐지율」이 유의미하게 나오지 않으면** 프로젝트의 존재 이유가 사라진다. W4 설계서에서 주제 재검토를 판정한다.
