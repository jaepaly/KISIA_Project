## 4. 2단 추론·조치 — D

### 4-1. 무엇을 하나

가명화된 스팬 묶음을 받아 **7속성 중 무엇이 특정 가능한지**를 판정하고, 조치를 추천하고, 단서 구간을 고쳐 쓴다. **실제 신상 값은 산출하지 않는다** — 계약 `stage2-io.schema.json` 에 값 필드가 없다 (설계 제약 1). 이게 이 프로젝트가 「추론기」가 아니라 방어 도구인 지점이다.

```
입력   Stage2Input   가명 텍스트 + B 의 스팬(type·level·subject) + C 의 k·delta
출력   Stage2Output  findings(7속성 verdict·evidence·confidence) + recommendation + rewrites
```

계약은 `docs/contracts/stage2-io.schema.json` v0.1.0 (D 소유 · E 수신). 8/24 초안 이후 #82(해외 `foreign`) · #115 반영.

### 4-2. 베이스 모델 — Qwen3-4B (DEC-004)

| | `qwen3:1.7b` | **`qwen3:4b`** |
|---|---:|---:|
| 계약 과제 245칸 정확도 | 91.0% | **93.5%** |
| 음성(단서 없음 → 기권) | 71.2% | **80.3%** |
| 의미상 근거 정확도 | 69.6% | **83.1%** |
| 함정을 근거로 쓴 인물 | 31/34 | 22/34 |
| 편당 지연 | 5.4s | 7.9s |

측정 2026-08-31 · corpus-v0 인물 35명 스팬 276건 · ollama 0.33.2 · RTX 3060 8GB · seed 20260901 · think=false — [`experiments/exp05-model-size/`](../../experiments/exp05-model-size/).

**갈린 자리는 「말을 아끼는 능력」이다.** 단서가 있을 때 발언은 98.3% 동률, 차이는 전부 기권과 함정 배제에서 났다. 8B 는 추론 VRAM 6GB 로 일반 노트북 밖이라 후보에서 뺐다 (`models/registry.md`).

⚠️ 한계 — prompt-only 스팬 판정에 한정. 「7속성 중 5개 적중」을 입증한 것이 아니다 (그 기준은 값 적중이고 계약에 값 필드가 없다).

### 4-3. 학습 — QLoRA

| 항목 | 값 | 근거 |
|---|---|---|
| 양자화 | NF4 · double quant · compute bf16 | exp07 |
| LoRA | r=16 · α=32 · q/k/v/o_proj · dropout 0.05 | 학습 파라미터 0.292% (11.8M) |
| 시퀀스 | **1024** · batch 1 · grad accumulation | 3060 8GB 피크 5.1GB. 2048 은 넘친다 → B 의 5070 12GB 또는 클라우드 (`setup-python.md` §5 폴백) |
| 환경 | torch 2.11.0+cu128 · transformers 5.15.1 · peft 0.20.0 · bnb 0.50.1 | 팀 공통 핀 |

측정 2026-09-07 — [`experiments/exp07-qwen3-finetune/`](../../experiments/exp07-qwen3-finetune/). 같은 코드가 처음엔 seq 1024 에서 14GB 로 OOM 났다 — `model.train()` 없이는 gradient checkpointing 이 적용되지 않는다. 가이드 스니펫도 같이 고쳤다.

**1순위 학습 목표는 함정 배제다.** exp05 에서 4B 도 34명 중 22명이 `subject: other` 스팬을 본인 속성의 근거로 썼다. 프롬프트로는 안 잡힌다.

### 4-4. 학습 라벨 — 설계에서 결정적으로 유도

교사 스팬 라벨이 아직 저장소에 없어(9/7 기준 `gold/` 에는 blind 110 스팬뿐) v0 은 **인물 설계 `clue_plan` 에서 `findings` 를 규칙으로 유도**한다. 합성 코퍼스라 정답을 설계자가 이미 적어놨다. 교사 LLM 은 `rewrites` 문장 생성에만 쓴다.

- 타깃 = 계약의 `findings` · `rewrites` **그대로**. `recommendation` 은 C 의 `delta`(W5) 뒤에
- 함정 판별에 `subject` 만 쓰면 틀린다 — **`subject: self` 인 함정이 29건**(과거거주 14 · 출신지 10 …). `note` 의 `통로=` 표지로 배제하되 그 표지는 입력에 넣지 않는다 → 모델이 시제·장소 성격으로 배운다
- 증강: 글 부분집합 (타깃이 규칙 유도라 글을 빼면 `narrowed → abstain` 으로 따라온다) — 115명 → ~1,000건
- 교사 스팬이 오면 입력 스팬을 그걸로 교체 → **1단·2단이 같은 `*_spans.jsonl` 을 읽는다** (킥오프 ⑤)

형식 초안: [`data/corpus/v0/gold/stage2/README.md`](../../data/corpus/v0/gold/stage2/README.md) (A·B 확인 대기).

### 4-5. 조치·추천·리라이트 (W8~W9)

- 추천 = C 의 `delta`·`greedy_min_set` 을 호출하는 쪽 (#124 ④). 부담 오름차순 · 삭제 권고는 `exceptional` 로 분리 (plan §2 조치 메뉴 ④)
- 리라이트 = 단서 구간만 교체. 의미 보존은 임베딩 유사도 + 가독성 (§7 지표)
- 가명화·복원 계층은 W5 — 치환 시 오프셋 저장 (문자열 치환만으로는 반드시 깨진다)

### 4-6. 2단 평가 지표 — 정확도 단독 금지 [MF-012]

「Qwen3 vs 외부 LLM 일치율 ≥ 0.8」은 정확도 계열이다. W4 설계서에서 **macro F1 기준으로 바꿀지 B 와 함께 정한다** — 이 수치가 「외부 전송 0」 주장의 근거라 혼자 바꾸지 않는다. 함께 쓸 것: 속성별 F1 + 혼동행렬 · 특이도/FPR · MCC · McNemar · 인물 단위 cluster bootstrap (`D-stage2.md` §7).

⚠️ 이 지표는 **학습된 Qwen3 v1(W7)** 로 잰다. exp04(Claude vs GPT) 가 아니다.
