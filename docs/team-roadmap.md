## 예상 질문 — 내가 보조로 답할 것부터 확인

> 「주로 답할 역할」이 아니어도, 같은 줄의 근거만 기억하면 대신 답할 수 있게 썼다. 모르는 것은 「담당이 정확한 숫자로 답하겠다」고 넘기면 된다. **「사람 수준」 같은 말은 쓰지 않는다**(사람 일치도 표본이 작아 신뢰구간이 넓다).

### W1~W4 — 데이터 · 계약 · 출발점
1. **왜 실제 블로그 글이 아니라 합성 데이터인가?** — 주로 A(보조 D·E)
   - 실제 글엔 「정답(누가 어떤 사람인지)」이 없고, 실제 글을 모아 커밋하는 것 자체가 개인정보 위험이다(`docs/RULES-DO-NOT.md`). 합성 인물은 설계 단계에서 단서(clue_plan)를 심어 두니 정답을 안다.
   - 사실감은 리얼리즘 카드 18장(실제 말투 참고)과 통독(A·B·C·E 몫 89명은 인물별 앞뒤 5편 · 역할별 5명 전편 표본, D 몫은 따로 통독) 뒤 전량 재생성(#201)으로 보강했다.

2. **라벨은 누가 어떻게 달았나? LLM 이 단 라벨을 믿어도 되나?** — 주로 A(보조 C·D)
   - 교사 LLM(Claude Opus 4.8)이 3,092편에 3,169스팬을 먼저 달고(#215), A·B·D·E 가 417편 587스팬을 사람이 검수했다(이슈 #216).
   - 따로 C 가 교사 결과를 보기 전에 혼자 blind 159편 267스팬을 달았다(#229) — 교사 라벨을 사람 기준으로 재는 잣대다.

3. **글 생성과 라벨에 같은 LLM 을 쓰면 순환 아닌가?** — 주로 D(보조 A)
   - 그래서 생성에 Claude(교사)·Qwen(2단 학습 대상)을 금지했다. W3 생성은 GPT 계열(#152), 교사는 Claude, 2단은 Qwen3-4B 로 계열이 다르다(이슈 #16 · `llm.py` `BLOCKED_GENERATION`).

4. **기존 개인정보 탐지 도구로는 안 되나? (프로젝트를 할 이유)** — 주로 B
   - W2 첫 비교에서 단서 문장 185건 중 정규식·Presidio 는 0건, 한국어 NER 은 9건(대도시 이름)만 잡았다(#106). 「서버 개발 3년차」「수인분당선 막차」 같은 문맥 단서는 셋 다 놓친다.
   - 이를 그냥 믿지 않으려고 중단 기준(미탐 ≥45% · 도달 ≥60%)을 측정 전에 정했고(이슈 #128), implicit 86.5% 로 통과했다(#202 · DEC-006).

5. **inferential 을 게이트에서 뺀 건 결과가 안 좋아서 기준을 바꾼 것 아닌가?** — 주로 D·B
   - 임계값을 낮추는 안은 「숫자를 결과에 맞추는 것」이라 버렸다. inferential 은 정의상 다른 단서와 합쳐야 좁혀지는데 측정이 문장 하나만 줬다 — 정의와 측정이 안 맞았다(DEC-006). 다른 모델(Opus 4.8)로도 51.5% 라 모델 문제도 아니었다(#228).
   - 인물 단위(여러 글 합친) 추론은 2단에서 따로 잰다고 적어 두었다.

6. **사람끼리 라벨 일치도(IAA)가 27% 면 정답이 흔들리는 것 아닌가?** — 주로 A·C
   - 1차 파일럿 16편 A·C 일치도 27.0%(#221). 어디서 갈렸는지(경계·등급·누락·유형)를 대조했고(#208), 그 결과로 라벨 스키마에 등급 가이드·스팬 분할 원칙을 추가했다(#211). 가장 갈린 등급이 inferential 이라 1단 목표치를 IAA 상한에 묶었다(DEC-006 「이어지는 것」).

7. **인터페이스 계약은 왜 W2 에 고정했나? 바꾸면 어떻게 되나?** — 주로 E·D
   - 다섯 명이 동시에 개발하려면 주고받는 형식(필드 이름·문자 offset 기준·null 처리)을 먼저 정해야 서로 안 기다린다(`docs/contracts/README.md`). `docs/contracts/` 는 CODEOWNERS 로 묶여 PR·소유자 리뷰 없이는 못 바꾼다.

8. **k값은 어디서 오고, 해외 거주자는 어떻게 하나? 2단은 왜 4B 인가?** — 주로 C(k·해외) / D(4B)
   - k 의 분모는 행정안전부 주민등록 인구통계(읍면동 × 5세 × 성별), 2026-07 기준 행정구역 3,922개(#98). 해외는 분모가 없어 「권역 한 단계 + UNKNOWN(산출 불가)」로 둔다(DEC-005).
   - 2단은 노트북(RTX 3060 8GB)에서 돌아야 해서 8B 를 빼고 1.7B·4B 를 비교, 4B 가 정확도 · 근거 · 형식에서 앞섰다(대신 지연은 5.4초 → 7.9초로 느리다). 다만 n=35 라 통계적으로 유의하다고는 말하지 않는다(DEC-004).
