# 모듈 인터페이스 계약

> **W2 최대 산출물.** 이 계약이 고정되지 않으면 다섯 명이 서로 기다린다.
> 주관: E(이지희) · 목요일 확정

## 왜 문서가 아니라 게이트인가

이 디렉터리는 `CODEOWNERS`에 걸려 있어 **변경에 2명 승인이 필요하다.**
여러 역할이 함께 쓰는 규격이라 혼자 바꾸면 다른 사람 코드가 조용히 깨진다.

## 계약 4종

| 파일 | 주는 쪽 | 받는 쪽 | 담는 것 |
|---|---|---|---|
| `span.schema.json` | B 최진필 | C · D · E | 탐지된 구간 (위치·유형·등급·점수) |
| `specificity.schema.json` | C 신정현 | D · E | k값 입출력 |
| `contribution.schema.json` | C 신정현 | D · E | 글별 기여도, 조치 후 재계산 |
| `stage2-io.schema.json` | D 박재현 | E | 종합 판정 결과, 추천 조합 |

## 그 밖의 공동 소유 문서

| 파일 | 공동 소유 | 비고 |
|---|---|---|
| `label-schema.md` | A 이은선 · B 최진필 | 라벨 스키마 (TAB 한국어 적응) |
| `geo-dictionary.md` | C 신정현 · D 박재현 | 지명 사전. **가명화기 = 특정성 엔진의 역함수** |

## 정하는 요령

**완벽할 필요 없다. 나중에 바꾸기 어려운 것부터 정한다.**

1. 필드 이름
2. 좌표 기준 — 문자 offset / 바이트 / 토큰 인덱스 (**문자 offset 권장**)
3. 단위
4. null·빈 값 처리

미정으로 두는 것이 제일 나쁘다. **일단 정하고 나중에 바꾼다.**

## 계층 경계도 여기 명시한다

플랫폼(가상 SNS)과 분석 도구가 무엇을 주고받는지, **무엇은 절대 넘기지 않는지**.
판단 기준 하나 — *"사용자 글의 원문이 우리 분석 서버로 넘어가나?"* 넘어가면 잘못된 설계다.
