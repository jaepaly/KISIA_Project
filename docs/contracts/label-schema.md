# 라벨 스키마

> **상태: 초안**
> 확정 위치: `docs/contracts/label-schema.md` · 공동 소유 A·B
> 기준: TAB(Text Anonymization Benchmark) 주석 가이드라인을 한국어·게시글에 맞게 손질

---

## 0. 이 문서가 정하는 것

합성 코퍼스의 **정답표를 어떻게 적을지**에 대한 약속이다. 이 문서가 확정되어야
① A가 골드셋을 매길 수 있고 ② B가 `span.schema.json`을 쓸 수 있고 ③ E가 목요일에 계약 4종을 머지할 수 있다.

이 문서가 정하지 **않는** 것: 위험도 계산(C), 종합 판정(D), 화면 표기(E).

---

## 1. 스팬 유형 목록

### 1-1. 유형을 몇 개까지 둘 수 있나 — 먼저 예산부터

유형을 늘리면 라벨이 `2n+1`개로 늘고, **유형당 골드셋 스팬 수가 그만큼 줄어든다.**

| 유형 수 | BIO 라벨 수 | 유형당 골드셋 스팬 (600~700 기준) |
|---|---|---|
| 8 | 17 | 75~88 |
| **10** | **21** | **60~70** |
| 14 | 29 | 43~50 |
| 20 | 41 | 30~35 ← 유형별 F1이 의미를 잃는다 |

유형별 F1을 내려면 유형당 최소 30~50 스팬이 필요하다. **상한을 10개로 잡는다.**
쪼개고 싶은 충동이 들면 유형이 아니라 `level`(등급)로 구분되는지 먼저 본다.

### 1-2. 제안 — 10개

7속성(`age` `sex` `location` `occupation` `family` `commute` `income`)에서 유도했다.

| 유형 | 무엇을 잡나 | 예 | 기여 속성 |
|---|---|---|---|
| `AGE` | 나이·연령대 신호 | 마흔여덟 / 서른넷 / 90년생 | age |
| `SEX` | 성별 신호 | 아내 관점 표현, 남편이 / 와이프가 | sex |
| `LOC_ADMIN` | 행정구역명 | 성수동 / 용인 / 기흥 | location |
| `LOC_FACILITY` | 시설·랜드마크·상호 | 신갈저수지 / 서울숲 / 성수역 | location |
| `REL_ANCHOR` | 거주·직장 **관계어** | 집 근처 / 집 앞 / 회사 앞 / 동네 | location, commute |
| `JOB` | 직업·직무·업종 | 생산관리 / 완성차 공장 / 카페 매니저 | occupation, income |
| `FAM` | 가족 구성·생애단계 | 첫째가 고등학교 배정 / 손주 돌잔치 | family, age |
| `COMMUTE` | 교통수단·노선·통근 패턴 | 2호선 / 자차 출퇴근 / 퇴근길 | commute, location |
| `INCOME` | 소비·지출 수준 신호 | 장비 값 / 회비 / 브랜드 | income |
| `MEME_GEN` | 밈·유행어 (B 사전 매칭용) | — (B 소유 사전) | age |

> **유형과 속성은 1:1이 아니다.** `FAM` 스팬 하나("첫째가 고등학교 배정")가 `family`와 `age`를 동시에 드러낸다.
> 그래서 **속성 매핑은 이 표에만 두고, 스팬 레코드에는 넣지 않는다.** 어느 속성으로 이어지는지는 C가 계산한다.

## 2. 단서 등급 (`level`)

| 등급 | 뜻 | 예 |
|---|---|---|
| `explicit` | 값이 그대로 적힘 | "마흔여덟" |
| `implicit` | 문맥상 거의 확정 | "완성차 공장 출장이 잦아서" |
| `inferential` | 여럿을 종합해야 도출 | "집 근처" + "신갈저수지" |

등급은 **스팬마다 하나** 부여한다. 전 스팬에 예외 없이 붙인다.

---

## 3. 위치 표기

| 항목 | 확정 |
|---|---|
| 단위 | **문자 offset** (토큰 인덱스·바이트 아님) |
| 구간 | `start` **포함** / `end` **미포함** — 파이썬 슬라이스와 동일 |
| 검증 | `text == body[start:end]` 가 항상 참이어야 한다 |

문자 offset을 쓰는 이유: 토크나이저는 바뀌지만 코퍼스는 살아남는다.
`end` 포함/미포함을 안 정하면 **전 코퍼스가 한 글자씩 어긋난다.**

---

## 4. 겹침 규칙

> **겹침 금지 · 최장 우선.**

BIO 태깅은 토큰 하나에 라벨 하나만 붙일 수 있어 겹치는 스팬을 표현하지 못한다.
이건 취향이 아니라 모델 구조에서 나오는 제약이다.

```
"집 근처라 자주 가는 신갈저수지"

✗ (0,17) 전체를 거주 단서로  +  (12,17) 신갈저수지를 시설로   ← 겹침, 표현 불가
○ (0,4)  집 근처   → REL_ANCHOR
  (12,17) 신갈저수지 → LOC_FACILITY                          ← 두 스팬으로 분리
```

관계어를 별도 유형(`REL_ANCHOR`)으로 둔 이유가 이것이다. 붙여 잡으면 겹침이 생기고, 안 잡으면 "집 근처"가 사라진다.

## 5. 스팬 레코드 형식

```json
{"start": 12, "end": 17, "text": "신갈저수지",
 "type": "LOC_FACILITY", "level": "inferential"}
```

**스팬에 붙는 필드는 위 5개까지.** (B의 모델 출력에는 `score`가 추가된다 — 모델 확률값이며 위험도가 아니다.)

| 넣지 않는 필드 | 이유 |
|---|---|
| `risk` `severity` | 같은 표현의 위험도가 문맥마다 다르다. 일관 라벨이 불가능 → C가 계산 |
| `attr` | 유형-속성이 1:n이다. §1-2 매핑표로 대신한다 |

---

## 6. 라벨하지 않는 것

**학력 · 학교 · 전공 · 정치성향 · 건강 · 지적 수준**은 유형 목록에 넣지 않는다.
방어 도구가 민감 속성 추론을 학습하면 그 자체가 무기가 된다. 코퍼스 생성 전에 확정한다.

## 7. ⚠️ 회의 안건 — 미결 5건

### 안건 1 — 함정(타인 정보)을 어떻게 표시하나 🔴

코퍼스 설계상 **오답 유도용 함정**을 심는다 — "동탄 사는 친구랑 밤낚시"에서 `동탄`은 본인 거주지가 아니다.
그런데 현재 스팬 레코드에는 이걸 표시할 자리가 없다. 라벨만 보면 `동탄`과 본인 거주지가 구분되지 않는다.

| 선택지 | 평가 |
|---|---|
| A. `subject: self / other / unknown` 필드 추가 | 문맥 독립적이고 일관 라벨 가능. `risk`와 달리 라벨러 둘이 갈릴 여지가 적다 |
| B. 유형에 `_OTHER` 접미 | 유형 수가 2배 → §1-1 예산 초과 |
| C. 글 단위 메타로 분리 | 스팬 단위 채점이 안 된다 |

**A 제안.** 다만 B가 "필드 추가 최소화" 입장이면 조정.

### 안건 2 — 관계어를 하나로 둘까 셋으로 쪼갤까

B는 `REL_HOME` / `REL_WORK` / `REL_COMMUTE` 로 분리 제안. 초안은 `REL_ANCHOR` 하나로 묶었다.

- 쪼개는 쪽: C가 거주지/직장을 구분해서 쓸 수 있다
- 묶는 쪽: 유형 예산 2칸 절약, 유형당 스팬 수 확보

**절충안**: `REL_ANCHOR` 하나로 두되 `COMMUTE`가 통근 관계어("퇴근길")를 흡수. 회의에서 결정.

### 안건 3 — 암묵 신체 표현을 스팬으로 잡나

> "무릎이 예전 같지 않네요"

나이 단서인가? 라벨러 둘이 가장 갈리는 지점이고, **여기서 갈리면 B의 암묵 F1 목표치(IAA 기준)가 흔들린다.**
잡기로 하면 경계도 정해야 한다 — "무릎이" 부터인가 "예전 같지 않네요" 까지인가.

### 안건 4 — 스팬 경계를 어디까지 잡나

> "첫째가 고등학교 배정 받았습니다"

`(0,11) "첫째가 고등학교 배정"` 인가 `(4,11) "고등학교 배정"` 인가.
**최장 우선 원칙과 별개로, 조사·서술어를 포함할지에 대한 규칙이 필요하다.**
제안: **명사구까지만, 조사·서술어 제외.** ("첫째가" → `첫째`)

### 안건 5 — `MEME_GEN`을 유형 목록에 넣나

B가 사전으로 매칭하는 밈·유행어. 유형 목록에 넣어야 골드셋에 정답이 생기고 채점이 된다.
넣으면 유형 10개(예산 상한), 안 넣으면 사전 성능을 못 잰다.

## 부록 — 샘플 문장 5개 (회의용)

**진행 방법**: 회의 시작 후 A·B가 **각자 따로 10분간** 라벨을 붙이고, 다른 부분만 비교한다.
다른 부분이 곧 안건이다. W3 IAA 파일럿의 축소판이기도 하다.

```
S-1  집 근처라 자주 가는 신갈저수지 조황입니다. 요즘 사람이 부쩍 많네요.
S-2  동탄 사는 친구랑 밤낚시. 걔는 차로 20분이라 편하다고.
S-3  새벽에 나섰더니 무릎이 예전 같지 않네요. 마흔여덟이 이런 건가.
S-4  첫째가 고등학교 배정 받았습니다. 둘째는 아직 중학교.
S-5  퇴근하고 기흥호수 한 바퀴. 공장에서 15분이면 와서 자주 옵니다.
```

각 문장이 겨냥하는 결정:

| 문장 | 겨냥 |
|---|---|
| S-1 | 겹침 규칙 · 관계어 분리 (§4, 안건 2) |
| S-2 | **함정 표시** (안건 1) |
| S-3 | 암묵 신체 표현 (안건 3) · `AGE`/explicit |
| S-4 | 스팬 경계 (안건 4) · 유형-속성 1:n |
| S-5 | 인접 유형 3종 혼재 · 통근 관계어 귀속 (안건 2) |
