# 선행 자산 이관 — 출처 감사 로그

> **왜 이 문서가 필요한가.** 계획서 §7은 선행 PoC 자산 이관을 *"약 1개월치 선점"* 이라 명시했고, **12주 일정이 성립하는 근거가 그 한 줄**이다. 그런데 §1 반박표가 교차모델 항목에 *"기존 측정은 제외된 R7~R10 기반"* 이라고 달아, **파생물 오염이 이미 확인**됐다.
>
> 무엇이 R7~R10을 보고 만들어졌는지 확인하지 않은 채로 가져오면, *"프라이버시 도구를 만들면서 무동의 개인 데이터를 단 한 건도 쓰지 않았다"* 는 이 프로젝트의 최대 주장이 깨진다. 벤치마크 공개도 불가능해진다.

**선행 PoC 위치**: `C:\NaverPrivacy` (PM 로컬)
**감사 시작**: W1 · **완료 목표**: W3

## ⚠️ 이관 원칙 3가지

**① `git merge` 를 쓰지 않는다.**
삭제한 파일도 히스토리에 영구히 남는다. R7~R10 파생물이 한 번이라도 히스토리에 들어가면 되돌릴 수 없다. **파일 복사 후 신규 커밋**으로만 가져온다.

**② 파일마다 출처를 3분류한다.**

| 분류 | 처리 |
|---|---|
| `R1~R6 only` | 이관 |
| `R7~R10 derived` | **폐기** |
| `mixed-unknown` | **폐기 또는 M1에 재생성** |

**③ 이 표가 그대로 4주차 설계서 「보안·윤리」 증빙이자 발표 슬라이드 1장이 된다.**

## 4. 이관 기록 규칙

자산을 가져올 때마다 위 표에 한 줄을 추가하고, 커밋 메시지에 원 경로를 남긴다.

```

원 위치: C:\NaverPrivacy\poc\data\{REALISM_GUIDE.md, realism_samples/}
```
