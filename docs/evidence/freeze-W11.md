## 외부 요청 0 — 분석기 · Veilo 프로세스가 연 TCP 연결

두 경로 각각 점검 22회(11개 × 2) + 다시 세기 11회 동안 분석기 · Veilo 프로세스의 연결을 0.2초마다 모아 중복을 뺐다(PowerShell `Get-NetTCPConnection -OwningProcess`). W8 ② 와 같은 방법이다.

| 원격 주소 | 무엇 |
|---|---|
| `127.0.0.1:*` | 요청 ↔ 분석기 (같은 PC) |
| `::1:3000` | 분석기 → Veilo 내보내기 API (같은 PC) |
| `0.0.0.0:0` · `:::0` | 대기 소켓 |

**외부 주소 연결: 규칙 경로 0개 · 모델 경로 0개** (모델 경로는 Qwen3-4B 베이스 · 어댑터 · 1단 체크포인트를 올리는 기동 구간 포함 — 허브 접속은 실제 모드 기본값으로 꺼져 있다 · [#320](../../../../pull/320))

- 화면 쪽 — `apps/analyzer/static` · `apps/sns/static` · `apps/sns/templates` 에 외부 주소를 부르는 코드가 없다(글꼴은 로컬 `pretendard` · 주소는 라이선스 주석 두 줄뿐). 브라우저 네트워크 탭 캡처는 W8 ①(`0 / 9 requests`) 뒤로 다시 찍지 않았다 — 촬영 때 C 가 같은 방법으로 볼 수 있다
- 외부 LLM 호출은 `apps/analyzer/external.py` 한 곳 · `ALLOW_EXTERNAL_LLM=false` 기본 — 이번 응답 22개 모두 `external_llm_used: false`
- **서버 실행(veilo.site)은 이번에 재지 않았다** — KISIA AWS 지원이 끝났다(10/26). 로컬 실행의 「외부 요청 0(localhost 제외)」만 이 증빙의 범위다
