## 1. 무엇을 재나 — 정확도 검증이 아니다

실제 글에는 정답 라벨이 없다. 그래서 「파도풀이 맞혔나」가 아니라 **글쓴이 본인이 결과를 보고 판단한 것**을 잰다.

| 지표 | 정의 |
|---|---|
| 본인 확인 정밀도 | 본인이 「맞다(내 정보가 드러난다)」고 한 단서 수 ÷ 화면에 표시된 단서 수 |
| 놓친 것 | 본인이 「이것도 나를 드러낸다」고 짚었는데 표시되지 않은 표현 수 (유형만 적는다 · 원문 금지) |
| 조치 이해 | 「위험 줄이기」 안내를 보고 무엇을 하면 되는지 알았나 (예 / 애매 / 아니오) |
| 걸린 시간 | 점검 시작 ~ 결과까지 · 전체 체험 시간 |

5명 안팎의 지인 표본이라는 한계를 결과와 같이 적는다.

| 문의 | 담당 E(이지희) · 연락은 동의서를 받은 경로로 |

## 5. 글 받기 · 분석 환경

**받기**
- 참여자가 **파일(.txt 또는 .json)** 로 직접 준다 — `.txt` 는 한 줄에 글 한 편 (파도풀 「파일로 점검」 형식). 메신저 단체방 · 공유 드라이브 링크로 받지 않는다
- 받은 파일은 바로 `data/consented/P0N/` 에 둔다 (`.gitignore` 로 커밋이 막혀 있다 · RULES-DO-NOT). 다운로드 폴더 · 바탕화면에 남기지 않는다
- **OneDrive · Google Drive 같은 동기화 폴더에 두지 않는다** — 저장소 폴더가 동기화 폴더 안이면 다른 로컬 폴더를 쓴다
- 받자마자 §2 제외 기준으로 한 번 훑어보고(사람이 직접 · AI 도구 금지), 걸리는 글은 빼서 파기

**분석 — E 또는 D 의 PC, 로컬로만**
- 분석 앱을 그 PC 에서 띄운다 (`localhost` · v2 체크포인트 + 규칙 · 2단 규칙). **veilo.site 에 올리지 않는다** (서버 접속 기록 14일 보관 · 처리방침)

```powershell
$env:ENGINE_MODE="real"; $env:STAGE2_MODE="rules"; $env:PYTHONPATH="src"; python -m uvicorn apps.analyzer.server:app --port 8000
```

- 브라우저는 **InPrivate(시크릿) 창** 하나만 → `http://localhost:8000/static/scan.html` → 「다른 서비스에서 내보낸 파일 올리기」. 업로드한 글은 서버 **메모리에서만** 읽고 디스크에 쓰지 않는다(1MB 상한 · `server.py` `upload_and_scan`)
- 실제 엔진은 모델 허브에 접속하지 않는다(외부 요청 0 · [network-zero](evidence/network-zero-W08.md)) — 분석 전에 DevTools Network 에 `localhost` 말고 나가는 요청이 없는지 한 번 본다
- **AI 도구 금지**: 그 PC 에서 Claude Code 등을 쓸 때 `data/consented/` 를 열거나 읽게 하지 않는다 · 결과 화면을 캡처해 AI 에 붙여 넣지 않는다
- 참여자가 화면을 보며 질문지에 답한다 — **만나서 같이 본다**. 화상 회의 · 화면 공유는 화면(글 원문)이 그 서비스 서버를 거치므로 하지 않는다 · 녹화 · 캡처 금지

## 7. 파기 — 분석한 그날, 참여자마다

**파기 범위** (빠뜨리기 쉬운 것까지)

| | 어디 | 어떻게 |
|---|---|---|
| ☐ | 업로드 원본 | `data/consented/P0N/` 폴더째 삭제 |
| ☐ | 브라우저 저장소 | 분석 앱은 결과를 **원문째** `sessionStorage` 의 `scanResult` 에 담는다(`common.js`) — **InPrivate 창을 모두 닫으면** 지워진다. 일반 창을 썼다면 사이트 데이터 삭제 |
| ☐ | 열린 결과 화면 | 탭 · 창 모두 닫기 |
| ☐ | 다운로드 · 캡처 | 다운로드 폴더 · 캡처 도구 저장 위치 · 클립보드 기록(Win+V) 확인 |
| ☐ | 받은 경로 | 메일 · 메신저로 받았다면 받은 파일 · 대화 첨부 삭제 |
| ☐ | 임시 파일 · 로그 | 업로드는 메모리에서만 읽지만, 분석 앱 **터미널 출력 · 오류 기록**에 글 조각이 남았는지 확인하고 터미널을 닫는다 · `%TEMP%` 에 해당 파일 없는지 |
| ☐ | 휴지통 | 삭제한 파일이 휴지통에 남지 않게 비운다 |
| ☐ | 메모 | 손으로 적은 메모에 원문이 있으면 파기 |
