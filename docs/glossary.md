# 표기 사전

> **왜 필요한가.** 팀명·역할·컴포넌트·지표 이름이 **17~18개 문서에 반복 기입**된다.
> 문서마다 표기가 흔들리면 8주차·10주차에 같은 것을 다른 이름으로 부르게 되고,
> 심사자에게는 서로 다른 것으로 읽힌다. **여기 적힌 표기만 쓴다.**

## 역할

| 문자 | 확정 표기 | 담당 |
|---|---|---|
| A | 데이터 리드 | **이은선** |
| B | 1단 탐지 모델 | **최진필** |
| C | 특정성·누적 | **신정현** |
| D | 2단 추론·조치 | **박재현** (팀장·PM 겸임) |
| E | 시스템·컴플라이언스 | **이지희** |

**배정 근거** — B·C는 1지망 단독. D는 지망자가 없어 팀장이 겸임(GPU 보유 확인).
A·E는 이지희·이은선의 지망이 `E→A`로 동일해 협의로 결정.

**표기**: 문서에서는 `이은선(A)` 형태로 쓴다. 경로·브랜치명에는 **ASCII 대문자만** (`A/c5/...`).

**경로·브랜치명에서는 ASCII 대문자만 쓴다** (`A/c5/...`).

## 자주 흔들리는 용어

| ✗ 쓰지 않는다 | ○ 확정 표기 | 이유 |
|---|---|---|
| 온디바이스 | **로컬 처리** | 110M·CPU 300ms는 데스크톱 수준. "온디바이스"는 모바일로 오해된다 |
| 크롤링 | **수집 경로 / 입력 어댑터** | 우리는 크롤링하지 않는다 |
| 브라우저 확장 | **가상 SNS 플랫폼** | v2.2에서 변경 ([DEC-001](decisions.md)) |
| 결합 재식별 위험 탐지·완화 시스템 | **공개 게시글 누적·결합에 따른 재식별 위험 자가진단 및 보호조치 추천 시스템** | 구 주제명(저장소 내부). 쓰지 않는다 |
| 개별 글들의 결합에서 발생하는 … 시스템 개발 | **공개 게시글 누적·결합에 따른 재식별 위험 자가진단 및 보호조치 추천 시스템** | 제출된 주제 초안(66자 서술형). W1에 변경 |
| 게시글 누적 분석 기반 … 자가진단 서비스 | **공개 게시글 누적·결합에 따른 재식별 위험 자가진단 및 보호조치 추천 시스템** | 검토 중 폐기된 안. '결합'이 빠져 있었다 |
| 개인용 프라이버시 영향평가: 공개 게시글 누적·결합 … 시스템 | **공개 게시글 누적·결합에 따른 재식별 위험 자가진단 및 보호조치 추천 시스템** | 저장소 내부 확정안(45자). **제출본과 다르므로 쓰지 않는다** |
| 개인용 프라이버시 영향평가 시스템 | **재식별 위험 자가진단 시스템** | 구 약칭. 정식명에 없는 표현이라 발표에서 어긋난다 |
| 개인정보 탐지 | **준식별자 탐지** | 명시 PII 탐지와 구분해야 차별점이 드러난다 |
| 익명화 | **가명화** | 법적으로 다른 개념이다 |
| 마스킹 | **조치** (리라이트/비공개/활동 메타 관리) | 우리 출력은 마스킹이 아니라 조치 추천이다 |
| 페르소나 | **합성 인물** (대외 문서) | 팀 내부에서는 페르소나로 불러도 된다 |
| 정확도 | **F1** 또는 **재현율** | 어느 것인지 명시한다 |

## 수치 인용 규칙

> **선행 실측치를 인용할 때는 반드시 "선행 PoC 자체 측정" 을 붙인다.**
> 논문 결과도, 공개 벤치마크 결과도 아니다. 완성된 결과로 오해되면 12주 목표가 붕 뜬다.

| 수치 | 정확한 표기 |
|---|---|
| 페르소나 7속성 추론 | **R1~R5는 7/7, R6는 6/7** — "6종 전부 7/7"이 아니다 |
| 누적 곡선 | 1편 26.7 → 5편 69.2 → 10편 71.9 → 19편 79.7 |
| 조치 3단계 효과 | R1 79 → 31 (−61%), R3 82.1 → 37.8 (−54%) |
| 외부 인용 | Staab et al., ICLR 2024 — top-1 **최대** 85% ("최대"를 빼지 않는다) |

**모든 성능 수치에 측정일 · 데이터 버전 · 모델 버전을 붙인다.**
