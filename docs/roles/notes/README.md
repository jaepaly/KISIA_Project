# 역할 노트

각자 자기 역할 매뉴얼([../](../))을 읽고 **자기 말로** 정리한 문서를 여기 둔다.
파일명은 `<본인이름>.md`.

## 왜 쓰나

1. 매뉴얼을 실제로 읽었는지 스스로 확인된다
2. **질문이 월요일 킥오프 안건**이 된다 — 모르는 걸 적는 게 목적이다
3. 첫 커밋이 되어 기여자 그래프가 성립한다

## 형식

```markdown
# 이름 (역할)

## 내 자리에서 만드는 것 — 내가 이해한 대로
(3~5줄. 매뉴얼을 옮겨 적지 말고 자기 말로)

## 잘 모르겠는 것
(질문. 많을수록 좋다)

## 이번 주에 내가 하기로 한 것
(README의 내 항목에서 옮겨 적기)
```
