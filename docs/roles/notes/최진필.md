# 최진필 (B · 1단 탐지 모델)

## 내 자리에서 만드는 것 — 내가 이해한 대로
- 사용자가 작성한 게시글에서 거주지, 나이, 직업 등 신상을 추론할 수 있는 준식별자(단서) 구간을 찾아내고 유형을 태깅해 주는 로컬 1단 탐지 모델 제작
- 프라이버시 검사를 위해 사용자 글을 외부 AI로 전송하지 않고 로컬에서 빠르고 가볍게(CPU 300ms) 동작
- 인코더를 적절히 파인튜닝하여 높은 스팬 F1 성능 확보

## 잘 모르겠는 것
- 골드셋이 없는 상태에서, 기존 도구로 20편 정도 눈으로 검수하면 충분한가? 아니면 직접 해보면서 찾아가야하나?

- 1단 탐지 모델 출력 규격 계약초안 확정 및 E(이지희)에게 전달
