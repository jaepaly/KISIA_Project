# 이은선 (A - 데이터 리드)

## 내 자리에서 만드는 것 — 내가 이해한 대로
실제 블로그를 긁어오면 문제가 생길 수 있으므로 직접 인물 카드를 설정해서 그를 기반으로 가상의 인물을 생성하고, 글을 작성한다.
이 때, 카드의 어조를 조금씩 변경해 인물마다 차별점을 둔다.

## 잘 모르겠는 것
- 코퍼스 3000 / 인물 100 인데, 인물 한 명 당 30개의 글을 작성해야 하는가
- BCDE가 작성한 인물의 JSON 파일의 검수는 누가 하는가
- 생성 모델과 교사 모델을 각각 어떤 것을 사용하는가

## 이번 주에 내가 하기로 한 것
- 화요일까지 B와 라벨스키마 확정
- 수요일까지 파이프라인 동작
- 수요일까지 BCDE에게 인물 JSON 양식 배포
- 카드 3~4장 추가 제작
- 시범 인물 10명, 글 200편 생성
- 리얼리즘 검수
- 교사 LLM 자동 라벨링 착수
