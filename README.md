## 이번 주 반드시 지킬 것

**① 보고서의 숫자는 출처가 있는 것만 쓴다.**
측정일 · 데이터 버전 · 체크포인트 · PR 번호가 붙은 숫자만 넣는다. 예비값(CPU 지연)과 「test 분석 반영 결과」(1단 개선)는 그렇게 표시한다.

**② test 로 다시 고르지 않는다.**
1단 구성·임계값·규칙은 이미 나온 test 점수를 보고 다시 고르지 않는다. 기존 test 비교(#294 · #295)는 한계 보고용이고, 구성 결정은 내부 eval 과 #293 결과로 한다.

**③ 새 실험보다 연결이 먼저다.**
이번 주 개발은 **이미 만든 엔진을 앱에 잇는 것**에 쓴다. 근사기 학습 · triage · 밈 사전 · 누적 엔진 고도화는 W9 이후로 (근사기 **평가 코드**는 이번 주). W9 말 동결이 목표이고, 못 끝낸 것만 W10 월~수에 마무리한다 ([roadmap 변경 기록 10/4](docs/roadmap.md)).
