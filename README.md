## ⚠️ 이번 주의 진짜 제약 — 사슬이 직렬이다

**한 칸이 밀리면 뒤가 전부 밀린다.** 그리고 사슬 끝에 중단 기준이 있다.

```
월 오전   생성 모델·경로 결정            (D·A)
   ↓
월~화     인물 100명                     (전원 — 각자 20명)
   ↓
화~수     글 3,000편 생성                (A·B·C·D 각자 계정)
   ↓
수~금     골드셋 600~700스팬 검수         (전원 분담)
   ↓
금        미탐 공간 크기 측정             (B)  ⭐
   ↓
금        중단 기준 판정 → W4 설계서 입력
```

**그래서 이번 주에 「나중에」가 없다.** 인물을 목요일에 쓰면 생성할 시간이 없고, 생성이 목요일에 끝나면 골드셋 검수를 못 하고, 골드셋이 없으면 B가 잴 것이 없다.

> **막힐 것 같으면 목요일이 아니라 월요일에 말한다.** 사슬이 직렬이라 한 사람이 늦으면 네 사람이 기다린다.

### 못 지킬 때의 축소 순서 — 미리 정해둔다

| 무엇을 줄이나 | 얼마나 | 왜 이 순서인가 |
|---|---|---|
| 1. 글 편수 | 3,000 → 2,000 | 골드셋은 글의 일부만 쓴다. 편수가 줄어도 스팬 수는 유지된다 |
| 2. 인물 수 | 100 → 70 | 축 다양성이 줄지만 판정은 가능하다 |
| 3. 골드셋 | 600~700 → 400 | **blind 200 은 사수한다** — IAA 가 B 의 목표치 상한이라 |
| ❌ 안 줄이는 것 | **미탐 공간 측정** | 이걸 못 하면 이번 주를 한 이유가 없다 |

### ⭐ 이번 주 인물에 반드시 넣을 것 둘

감사에서 나온 구멍이다([#116](../../issues/116)). **20명 중 최소 절반에 넣는다.**

**① 성별 단서를 `clue_plan` 에 넣는다**

지금 35명 중 30명이 성별 단서가 없다. `scoring_keywords` 에만 있고 `clue_plan` 에 없어서 **스팬 라벨이 안 생긴다.** 그러면 7속성 중 성별만 F1 을 못 낸다.

한국어에는 성별이 새는 고유 통로가 있다. 실물은 `D07` · `D08` 에 있다.

| 통로 | 예 | 왜 |
|---|---|---|
| **호칭 체계** | 「**언니**가 준 원피스」 | 여성은 손위 여성을 언니, 남성은 누나라 부른다 |
| **복합 자기지칭** | 「늙은 **홀아비**」 | 한 어절에 연령·성별·혼인상태가 겹친다 |
| **통념 역행** | 손주 반찬을 직접 하는 남성 | 단독으로는 성별을 **반대로** 가리킨다 |

**② 함정 문형을 바꾼다**

`subject: other` 단서 31건 중 22건이 **「X가 Y 살아서 거기서 …했다」** 한 문형이다. 표면형이 같으면 모델이 「살아서」만 외우고 귀속 추론을 안 해도 점수가 나온다.

**B01~B05 가 참고가 된다** — 다섯 개 전부 거주가 아니라 직장·이직·개업으로 지명이 등장한다.

```
✗  친구가 해운대 살아서 거기서 만났다
○  친형이 여수 산단 정유사로 작년에 먼저 이직해서 조언을 많이 해줬다
○  후배 작가가 성수동에 대형 스튜디오를 새로 열어 오픈 축하차 다녀왔다
○  친구 직장이 P라 그 근처에서 저녁을 먹었다
```

### 목~금 — 미탐 공간 크기 측정 ⭐⭐

**골드셋이 기준이다.** A 가 수요일까지 골드셋을 내면 목요일부터 잴 수 있다.

```
미탐 공간 = 골드셋 스팬 중 기존 도구 3종이 하나도 못 잡은 것의 비율
```

**등급별로 분해해서 낸다.** 전체 하나로 내면 「명시는 잡고 암묵은 못 잡는다」가 묻힌다.

| 등급 | 기존 도구가 잡나 | 우리 값어치 |
|---|---|---|

## ⭐ 골드셋 — 다섯 명이 나눠서 검수한다

골드셋 600~700 스팬을 A 혼자 검수할 수 없다.

| 누가 | 무엇을 | 얼마나 |
|---|---|---|
| **A · C** | **blind 200** — 교사 라벨을 보지 않고 처음부터 + **IAA 파일럿**(같은 글 20편) | 각 100 |
| **B · D · E** | 교사 라벨 검수 | 각 130~150 |

> **blind 200 이 왜 A·C 공동인가.** 교사 LLM 이 만든 라벨로 모델을 학습시키면 순환 논리가 된다. 그 고리를 끊는 유일한 수단이 **정답을 안 보고 매긴 라벨**이고, 두 사람이 같은 글을 매겨야 사람끼리 얼마나 일치하는지(IAA)가 나온다. 그 수치가 **B 의 암묵 F1 목표치의 상한**이 된다.

### 스팬 레코드 형식 (`label-schema` §8-1)

```json
{"span_id": "S01_b07_s02", "text_id": "body",
 "start": 12, "end": 17, "text": "신갈저수지",
 "type": "LOC_FACILITY", "level": "inferential", "subject": "self"}
```

**붙는 필드는 이 8개까지.** `start`/`end` 는 **문자 offset** 이다 — 바이트나 토큰 인덱스가 아니다.

⚠️ **겹치는 스팬은 금지 · 최장 우선.** BIO 가 겹침을 표현하지 못한다.

⚠️ **밈과 세대 신호는 스팬으로 잡지 않는다**(`label-schema` §7). 글 단위 플래그 `flags.meme_hits` · `flags.gen_signal` 로 간다. 「무릎이 예전 같지 않네요」 같은 것을 스팬에 넣으면 라벨러끼리 갈려서 IAA 가 깎이고, **B 의 목표치가 IAA 에 묶여 있어** 목표치까지 같이 깎인다.

## 이번 주 반드시 지킬 것 3가지

**① 인물을 쓰기 전에 `corpus_audit.py` 를 돌린다.**
빈 축을 보고 고르지 않으면 이미 꽉 찬 축에 20명을 더 쓰게 된다. 그만큼 버린 것이 된다.

**② 막힐 것 같으면 목요일이 아니라 월요일에 말한다.**
이번 주는 사슬이 직렬이다. 한 사람이 늦으면 네 사람이 기다린다. 축소 순서는 위에 미리 적어뒀다.

**③ 실데이터는 절대 커밋하지 않는다.**
실제 블로그·SNS 글을 긁어오지 않는다. 지인 글도, 공개된 글도 안 된다. 훅과 CI 가 막지만 **막히면 우회하지 말고 왜 막혔는지 본다.**

전체 목록은 [docs/RULES-DO-NOT.md](docs/RULES-DO-NOT.md).

## 막히면

| 상황 | 어떻게 |
|---|---|
| 생성이 안 돈다 | `--provider echo` 로 배선부터 확인. 그래도 안 되면 `pip install -e .` 을 했는지 |
| 검증기가 ERROR 를 낸다 | 메시지에 계약 조항 번호가 있다. 그 조항을 먼저 읽는다 |
| 다른 사람 산출물이 안 와서 못 한다 | **가짜 데이터로 먼저 만든다.** 형식만 맞으면 나중에 교체된다 |
| 내 자리 일이 뭔지 모르겠다 | [docs/roles/](docs/roles/) 자기 매뉴얼 → 그래도 모르면 PM |
| 커밋이 훅에 막혔다 | 메시지에 이유가 있다. `--no-verify` 를 쓰기 전에 PM 에게 |
| 일정이 안 될 것 같다 | **미리** 말한다. 금요일에 말하면 대응할 시간이 없다 |
