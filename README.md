#### 명시 F1 — 11/2 에 무엇을 판정 값으로 적나 (PM 결정 10/25 · 측정 전에 고정)

- **판정 값 = proxy** — [#276](../../issues/276) (가) 산식(전체 정밀도 × 명시 재현율의 F1) 그대로. W7 의 0.5142 와 같은 식이라 비교가 된다
- **함께 적는 것** — 등급 판정(`resolve()`) 포함 값 · 유형별 값 · **신뢰구간(글 단위 부트스트랩)** · 오탐 분해(어떤 유형 · 등급에서 나왔나) · exact 와 #276 (나) 보수적 하한(참고치) · W7 값과 골드 관례가 다르다는 주의 — #357 로 test 13스팬의 등급이 바뀌었다(주 지표 partial 은 등급을 안 봐 영향 없지만 명시 F1 같은 등급별 숫자는 영향이 있다)
- **왜 proxy 인가** — ① 계약(label-schema)에는 명시 F1 산식이 따로 없고, W7 부터 써 온 식이 #276 의 proxy 다 ② `resolve()` 의 등급 관례는 test blind 골드를 보며 맞춘 것이라, 그 값은 독립 측정이 아니다 ③ 측정 뒤에 여러 산식 중 하나를 고르면 지표를 고르는 셈이다 — 그래서 **11/2 전에 정해 둔다**
- **test 를 보고 골드를 다시 검수하거나 임계값을 바꾸지 않는다** — 1단 임계값 **0.7 그대로**
- 읽는 법 한 줄: proxy 는 전체 정밀도 P 를 명시 등급에도 쓰므로, 명시 재현율이 1 이어도 **2P/(1+P)** 를 넘지 못한다(W7 의 P 0.399 → 상한 약 0.57). 0.80 에 닿을지는 재현율보다 **정밀도(암묵 · 추론 오탐 포함)** 가 정한다 — 이번 주 정밀도 규칙이 그쪽이다
