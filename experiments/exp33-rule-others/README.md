# exp33-rule-others: 1단 subject 규칙 보강 — 이웃 + 사람 명사 · 사투리 부모 호칭 · 나이 관용구

**왜** (10/17 · PM 결정 「가+나」): exp32 사후 분석에서 학생 판정(H)과 무관하게 남는 함정 오탐 4개가 모두 1단 규칙의 빈틈이었다.

| 패턴 | 예 (exp32 D1e · 이미 본 문장) | 지금 | 정답 |
|---|---|---|---|
| P1 이웃 + 사람 명사 + (조사 없이) 단서 | 「옆집 할머니 올해 ⟦여든둘⟧」 「윗집 사람은 매일 ⟦광역급행 통근⟧」 | self | other |
| P2 사투리 · 변이형 부모 호칭 | 「⟦아부지⟧ 트럭 얻어 타고」 | self | other |
| P3 나이 관용구 | 「마음만은 아직 ⟦열여덟⟧」 | self | other |

학생 모델 계열(exp30 ~ 32)은 접는다(exp32 §8 · 사후 분석). 이 실험은 **규칙만** 바꾼다(`src/kopl/c1_span/attributes.py`). 화면 쪽 대응(unknown 점선 표시)은 별도 PR(`D/sns/unknown-place-hint`).

이 문서 · `score.py` · 판정 문장은 **규칙 구현 전에** 커밋한다.

## 1. 판정 문장 — `data/cases.jsonl`

- **규칙 구현을 보지 않은 워커**가 패턴 설명만 보고 지었다(src · experiments 를 열지 않음). 64줄: P1 pos 16 · neg 10 · P2 pos 12 · neg 8 · P3 pos 10 · neg 8
- pos = 패턴에 해당해 정답 other · neg = 비슷하지만 정답 self 인 반례(「옆집 할머니가 몇 살이냐 묻길래 ⟦마흔⟧이라 했다」 「⟦시어머니⟧가 …」 「마음만은 스무 살인데 실제론 ⟦마흔다섯⟧」 「아들만 둘 키우는 ⟦엄마⟧라」)
- **D 검토 제외 2** (결과 전): P2-07 「어머님」(시어머니일 수 있어 정답 모호) · P3-03 「영원한 스물아홉으로 살기로」(실제 나이일 수 있음) → 62줄
- **규칙 구현자는 이 파일을 보지 않는다** — 구현은 위 표의 패턴 설명과 exp32 예 4개, 구현자가 직접 지은 단위 테스트로만 한다

## 2. 비교

| 이름 | 무엇 |
|---|---|
| **A** | main 의 `attributes.py` |
| **R** | 이 브랜치의 `attributes.py` (규칙 보강) |

두 파일을 같은 입력에 그대로 불러 `subject_of` 를 비교한다 — 1단 모델(스팬 탐지)은 그대로라 GPU 가 필요 없다.

## 3. 지표 · 판정 (사전 등록)

- **판정 문장**: 패턴 · pos/neg 별 정답 일치 수(A · R)
- **골드 회귀**: test 255편을 뺀 코퍼스 골드의 모든 스팬(모든 채널)에 A · R 의 `subject_of` 를 부르고 골드 subject 와 비교. 사람 검수(`reviewed`)와 전체(교사 라벨 포함)를 따로 센다. **lost** = A 는 골드와 맞고 R 은 틀림 · **fixed** = 반대. 바뀐 스팬은 전부 `results/gold_changes.jsonl` 에 남긴다

R 채택 = 모두 만족:
1. pos — 패턴마다 R 정답 비율 **≥ 0.75**
2. neg — R 정답 수 ≥ A 정답 수, 그리고 **A 가 맞힌 반례를 R 이 하나도 틀리지 않는다**
3. 골드(사람 검수) lost **≤ 1**
4. 골드(전체) lost **≤ 5**, 그리고 R 일치 수 ≥ A 일치 수
5. 기존 단위 테스트(`python -m kopl.c1_span.test_span` · `test_attributes`) 통과

- 골드 lost 가 나오면 문장을 읽고 README 에 적는다(정답이 틀린 골드일 수도 있다 — 판정은 숫자 그대로)
- 기존 규칙의 빈틈(예: 「아들만 둘 키우는 ⟦엄마⟧라」를 A 가 other 로 보는 것)이 neg 에서 드러나도 기준 2 는 「새로 틀리지 않기」만 본다

  - P1 과잉: 「나는 옆집 부부가 추천해 준 회사에서 ⟦개발자로⟧ 일한다」 · 「나는 옆집 총각이 소개해 준 집에서 ⟦서른⟧ 생일을」 — self → other

  - P3 과잉: 「설레는 마음은 ⟦서른 살이⟧ 된 오늘도」 · 「나는 이제 ⟦이팔청춘⟧, 딱 열여섯이다」 — self → other
  - P2: 사투리 호칭은 자녀 표지가 있어도 other 로 덮어써 「아이 재우고 ⟦엄니는⟧ 이제야 밥을」(글쓴이가 엄마) 이 self → other
  - 긴 공백에서 정규식이 O(n²) 로 느려진다(8,000자 공백 0.3 ~ 0.6초)

## 7. 결론

- **R 은 채택하지 않는다.** 사전 기준 1(P1 0.50)에서 떨어졌고, 등록 셋 밖에서 양방향 회귀가 확인됐다. `a576a68` 은 PR 로 올리지 않는다
- 판정 문장 셋이 반례를 26개만 담아, 규칙이 넓어질 때 생기는 과잉(소개 · 추천 · 묻다 · 생일)을 잡지 못했다 — 다음 규칙 실험은 반례를 패턴당 수십 개로, 구현자가 아닌 쪽(Codex 등)이 결과 전에 만들게 한다
- 살릴 만한 것은 **P2 의 호칭 낱말 추가**뿐이다(판정 11/11 · 반례 8/8). 다만 이번 구현은 자녀 문맥 판정까지 바꿨다 — 낱말만 `_PARENT_TERM` 에 더하는 최소안은 따로 재야 한다(이 셋은 이미 봤다)
