# exp-023: 네거티브 컨트롤 — 잡담만 쓴 계정의 위험도

## 무엇을 왜 재는가

C 성공 기준 「7속성 risk 가 나오고, **N1(네거티브)에서 15 미만**」([C-specificity.md](../../docs/roles/C-specificity.md) §12)과
회귀 테스트 4종 중 ③ 네거티브([howto/c-engine.md](../../docs/roles/howto/c-engine.md) §6)에 답한다.
「아무 글에나 위험하다고 하는 것 아니냐」는 반박에 숫자로 답하려는 실험이다.

N1 은 선행 PoC 인물이라 저장소에 없다(PoC 자체 측정 N1 = 8.8 — 인물 1명). 대신 코퍼스의 **잡담 글**
(`negative_control: true` — 생성 계약상 단서 0 · 시딩 때 위치태그도 붙지 않는다)만 모아
**인물마다 「잡담만 쓰는 계정」**을 만든다. 115명 · 1,978편 (계정당 5~22편).

위험도는 분석 앱과 같은 길로 잰다 — 스팬 → `conditions_from_posts`(본인 단서 · 여러 글 교집합) → `risk_total`.
(앱 `apps/analyzer/engines/c23.py` 의 `baseline_risk` 와 같은 계산)

## 설정

| 항목 | 값 |
|---|---|
| 측정일 | 2026-10-11 |
| 데이터 버전 | corpus-v0 p2.3 (v1 동결 d4cf8cb) · 골드 = 교사 라벨 + 사람 검수 (`data/corpus/v0/gold/*_spans.jsonl`) |
| 스팬 (gold) | 골드 라벨 — 잡담 1,978편 중 1,608편에 라벨이 있다. 라벨 없는 370편은 스팬 0 으로 센다(위험을 낮게 보는 쪽) |
| 스팬 (model) | 앱 1단 = **기준선 v2**(`model.safetensors` SHA-256 `d7dc7b06…`) + 명시 규칙(`C1_RULES` 기본 켬) · 임계값 0.7 · 제목 · 본문 · 사진 캡션 |
| 하드웨어 | AMD Ryzen 5 5600X (CPU) · model 실행 534초 |
| 환경 | Python 3.11.15 · torch 2.12.1 · transformers 5.12.1 |

## 결과

| 스팬 | 위험 중앙값 | 평균 | p90 | 최대 | **15 미만 계정** | 0 인 계정 |
|---|---:|---:|---:|---:|---:|---:|
| 골드 라벨 | **5.71** | 9.88 | 23.57 | 42.14 | **83 / 115** | 38 |
| 앱 1단 (v2 + 규칙) | **14.29** | 15.19 | 27.86 | 50.00 | **59 / 115** | 12 |
| (비교) 같은 골드로 **계정 전체**(잡담 + 단서 글) | 45.00 | 39.63 | | | 21 / 115 | |

- **중앙값은 두 경우 모두 15 미만**이다. 잡담만 쓴 계정(5.71)과 계정 전체(45.00)가 크게 갈린다 — 엔진이 「단서 글이 쌓인 계정」과 「잡담 계정」을 구분한다
- 다만 **계정 단위로는 15 이상인 잡담 계정이 있다** — 골드 32개 · 모델 56개
- 위험이 높은 잡담 계정(모델 기준 상위: A14 50.0 · B06 38.6 · A19 36.4 · B13 36.4 · A11 34.3)은 성별(배우자 호칭) · 가족 · 직업 · 통근 단서가 잡담 여러 편에 흩어져 쌓인 경우다. **골드 라벨에서도 같은 계정이 상위**다(B06 42.1 · B13 40.7 · A21 35.0 · A11 33.6 · A19 32.1)

## 해석

- 원래 기준 「N1 에서 risk < 15」는 **특정 인물 한 명**(PoC N1)에 대한 것이라 이 실험으로 그대로 충족했다고 할 수 없다. 말할 수 있는 것은 **「잡담 계정 115개의 중앙값이 15 미만」**(골드 5.71 · 모델 14.29 — 모델은 경계에 가깝다)이고, 모델 기준으로는 절반 가까이(56/115)가 15 이상이다. 진행률 판정은 이 범위로 한다
- 잡담 계정의 위험에는 **잡담 안의 실제 단서**가 섞여 있다 — 골드 라벨(교사 + 사람 검수)에서도 잡담 1,608편 중 423편에 604스팬이 있고, 골드 기준으로도 32개 계정이 15 이상이다. 모델 스팬과 골드 스팬을 하나씩 대조하지는 않았으므로, 모델 쪽 위험 중 얼마가 오탐인지는 이 실험으로 정하지 못한다. 「잡담은 단서 0」이라는 생성 계약과 「자영업 · 농업 · 가족 이야기가 일상인 사람의 잡담」이 어긋나는 문제(README 장기 미결 · #201 남은 쟁점)가 그대로 드러난 것이다
- 모델이 골드보다 높은(14.29 vs 5.71) 차이에는 1단 오탐과, 골드 라벨이 없는 370편(골드 쪽에서 0 으로 셈)이 둘 다 들어 있을 수 있다 — 나누지 않았다. 1단 정밀도가 병목이라는 기존 진단(registry · W9 D 4번 JOB 오탐)과는 같은 방향이다
- 그래서 정리서에는 「잡담만 쓴 계정 115개의 위험 중앙값 5.7(골드 라벨) · 14.3(앱 1단) — 같은 골드로 잰 계정 전체 45.0 과 구분된다. 단 잡담에도 단서가 섞인 계정은 15 이상이 된다(앱 기준 56/115)」로 적는다

## 한계

- 선행 PoC 의 N1(인물 1명 · 8.8)과 같은 대상이 아니다 — 같은 질문을 115개 계정으로 다시 잰 것이다
- 「잡담」은 생성 계약상의 표시다. 실제로는 단서가 있는 글이 섞여 있어 순수한 네거티브가 아니다
- 위치태그 · 프로필 소개는 넣지 않았다 (잡담 글에는 시딩 때 위치태그가 붙지 않는다)
- 골드 라벨이 없는 370편은 스팬 0 으로 셌다 — 골드 결과는 낮은 쪽으로 치우칠 수 있다
