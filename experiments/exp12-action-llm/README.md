# exp12-action-llm: 조치 후 교사 LLM 재추론 — 위험도가 내려가면 LLM 도 덜 맞히는가

## 1. 왜 재나

exp10 은 조치 3단계로 **우리 엔진의 위험도**가 −58.8% 내려간다는 것을 보였다. 하지만 그 위험도를
매긴 것도 우리 엔진이라, 「조치가 실제 추론을 막는다」의 증거로는 자기참조다.
exp12 는 조치를 실제 글에 적용한 뒤 **교사 LLM 이 다시 읽었을 때 덜 맞히는지**를 잰다.

## 2. 설계

| 항목 | 값 |
|---|---|
| 표본 | exp11 인물 10명 × w19 (created_at 순 앞 19편) — exp11 과 같은 글 묶음 |
| 조치 결정 | exp10 `run_persona` 를 **w19 안에서** 다시 돌린다 (전체 이력 결과를 쓰지 않는다). 위험도 = C2 `risk_total` · 스팬 = 최상위 골드 · 위치태그 = `scripts/seed_sns.py` |
| 조건 (누적) | c0 기준(19편 · 위치태그 포함) → c1 비공개(LOO greedy 앞 k편 제외 · k = exp10 규칙) → c2 + 남은 글 위치태그 제거 → c3 + 남은 글의 명시 단서 스팬을 그 채널(제목·본문·캡션)에서 삭제 |
| 교사 | `claude-sonnet-4-6` (exp11 과 같다) · system 프롬프트·출력 스키마 exp11 그대로 · KISIA 게이트웨이 |
| 입력 | exp11 형식(post_id · created_at · texts) + `geo_tag`. `window_id` 는 4조건 모두 `<인물>_w19` 로 같게 둬 조건을 드러내지 않는다 |
| 판정 | exp11 README §4 규칙 그대로 · 주 분석 열 `correct_e03_current_location` |
| 호출 수 | 40회 (10명 × 4조건) · 280칸 |

c0 도 다시 부르는 이유 — exp11 입력에는 위치태그가 없었다. c0 를 exp11 w19 결과로 대신하면 「태그 있는 기준」과 「태그 없는 exp11」을 비교하게 된다.

## 3. 결과 (2026-10-03 · 10명 · 40회 · 280칸)

| 조건 (누적) | 교사 LLM 적중 수 (평균, /7) | 위치 적중 | 엔진 위험도 (평균) |
|---|---|---|---|
| c0 기준 (19편 · 태그) | 4.90 | 10/10 | 43.07 |
| c1 비공개 (2~3편) | 3.60 | 8/10 | 17.50 |
| c2 + 위치태그 제거 | 3.70 | 7/10 | 15.14 |
| c3 + 명시 단서 삭제 | 4.00 | 8/10 | 12.79 |
| **c0 → c3** | **−18.4%** (줄어든 인물 6 · 같음 1 · 늘어난 인물 3) | | **−70.3%** |

단계별 (입력이 실제로 바뀐 인물만)

| 단계 | 인물 | LLM 적중 변화 (줄어듦 · 같음 · 늘어남) | 평균 | 엔진 위험도 변화 |
|---|---|---|---|---|
| 비공개 | 10 | 8 · 0 · 2 | **−1.3** | −25.6 |
| 위치태그 제거 | 5 | 1 · 3 · 1 | 0.0 | −4.7 |
| 명시 단서 삭제 | 5 | 0 · 4 · 1 | +0.2 | −4.7 |

속성별 적중 인물 수 (c0 → c1 → c2 → c3): 나이 8·4·4·5 · 성별 9·6·6·7 · **위치 10·8·7·8** · 직업 9·7·7·6 · 가족 7·6·7·8 · 통근 4·4·5·5 · 소득 2·1·1·1

같은 입력 재호출(조치 대상이 없어 입력이 같은 인접 조건 10쌍): 적중 수 차이 평균 0.3 · 바뀐 쌍 3

판정: 280칸 중 기권 105 · exp11 과 같은 인물·속성·문자열이라 exp11 판정 재사용 88 · 새로 판정 87 (PM 세션이 exp11 선례 — 나이는 참값을 포함하는 연령대면 정답, 위치는 상위 행정구역까지 정답·복수 후보 오답, 확정하지 않은 「A 또는 B」 직업은 오답 — 를 따라 판정. `judged_by` 열로 구분)

### 해석 (탐색적 관측 — 10명 · 단일 호출)

1. **이번 표본에서 비공개 후 LLM 적중 수가 줄었다.** 19편 중 기여도 상위 2~3편을 내리자 10명 중 8명의 적중 수가 줄었다 (평균 −1.3개). 나이·성별·직업이 주로 빠졌다.
2. **위치태그 제거·명시 단서 삭제 뒤에는 추가 감소가 관측되지 않았다.** 두 단계의 변화(0.0 · +0.2)는 같은 입력 재호출 변동(평균 0.3)과 비슷한 규모라 효과의 유무를 이 측정으로는 확정할 수 없다. 엔진은 두 단계에서 각각 −4.7 을 매겼다.
3. **엔진 위험도 감소가 LLM 적중 감소로 같은 비율만큼 이어지지 않았다 — 엔진 −70.3% · LLM −18.4%.** 두 수치는 척도가 달라(축별 해상도 평균 vs 맞힌 속성 수) 비율을 직접 보정하는 근거는 아니다. 엔진은 라벨된 단서만 보고 LLM 은 남은 16~17편의 문맥 전체를 읽는다는 차이가 원인 후보지만 이 실험으로 검증한 것은 아니다. 위치는 조치를 다 한 뒤에도 10명 중 8명이 맞혔다.
4. 따라서 exp10 의 「조치 3단계 위험도 −58.8%」는 **엔진 기준 수치**로 표기하고, 이 결과를 나란히 적는다. 실제 리라이터(W9)와 더 큰 표본에서 다시 재기 전까지 일반화는 유보한다.

## 4. 한계

- **리라이트는 삭제 모사다.** 실제 리라이터(W9)는 단서를 지우지 않고 바꾼다. 삭제는 문장이 어색해져 LLM 에 「뭔가 지워졌다」는 신호를 줄 수 있다
- **교사 순환.** 스팬(교사 라벨 포함)과 추론 LLM 이 같은 Claude 계열이다 (exp11 과 같은 한계)
- **10명 · 40회 1회 호출.** temperature 를 CLI 에서 정할 수 없어 반복 측정이 없다. 조치 대상이 없어 입력이 같은 조건(예: 태그·명시 단서가 없는 인물의 c1 = c2 = c3)을 같은 입력 재호출로 보고 흔들림을 따로 센다
- **위치태그는 seed_sns 모사**다 (잡담 제외 글의 30%)
- **판정자도 Claude(PM 세션)다.** 87칸을 exp11 선례에 맞춰 판정했고 독립 판정자·IAA 는 없다. 나이는 참값을 포함하는 연령대, 위치는 상위 행정구역까지 정답으로 허용하는 exp11 규칙이라 조치 후 추론이 덜 정밀해진 변화(예: 구 → 시)는 적중 수에 드러나지 않는다

## 5. 재현

```bash
export PYTHONIOENCODING=utf-8
python experiments/exp12-action-llm/build_inputs.py                       # data/inputs.jsonl (40행) · results/inputs_manifest.json
python experiments/exp12-action-llm/run_teacher.py --dry-run
python experiments/exp12-action-llm/run_teacher.py --env-file <팀 게이트웨이 .env>   # data/teacher.jsonl (중단되면 다시 실행)
python experiments/exp12-action-llm/make_judging.py                       # results/teacher_scored.csv — 빈 판정 칸을 사람이 채운다
python experiments/exp12-action-llm/score.py                              # results/metrics.json
```

`data/*.jsonl` 은 커밋하지 않는다 (재생성 가능). 판정표 `results/teacher_scored.csv` 가 커밋된 재현 입력이다 (exp11 과 같다).
