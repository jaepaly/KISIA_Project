# exp16-attributes: 스팬 level·subject 규칙 판정

## 1. 왜

1단 BIO 모델은 21개 라벨(유형)만 예측하고 `level`·`subject` 는 예측하지 않는다. 그래서 추론기·앱은 모든 스팬에 임시값 `implicit/self` 를 붙여 왔다 (#266).

| 임시값 때문에 생긴 일 | |
|---|---|
| 타인 단서도 본인 것 | 「친구가 [화정에서] 공방 한다」의 화정이 내 사는 곳으로 k 를 좁힌다 — 코퍼스가 일부러 심은 함정(label-schema §4-2)을 그대로 밟는다 |
| explicit 이 하나도 없다 | 「본인 명시 단서」를 다루는 추천 엔진의 리라이트 조치와 바꿔 쓰기(exp15)가 **실제 앱에서 한 번도 돌지 않는다** |

## 2. 무엇을 만들었나 — `src/kopl/c1_span/attributes.py`

`resolve(texts, candidate) → {level, subject}` — `infer.py` 의 `resolver` 자리에 그대로 들어간다. 앱(`apps/analyzer/engines/real.py`)을 이것으로 바꿨다.

- **level** — label-schema §4-1 실무 판단 순서: ① 수치·고유명사가 그대로 → explicit ② 표현에 값이 거의 없음 → inferential ③ 나머지 → implicit. 유형마다 ①②를 가르는 표지(한글 수사·숫자 나이 · 국내 지명 · 고유 이름이 있는 시설 · 노선·번호 · 직업명 · 금액)
- **subject** — §4-2 국소성 원칙: **스팬이 속한 문장만** 본다. other 는 문장이 타인에게 명시적으로 귀속시킬 때만
  - 앞에 타인 주어(「친구가 · 시누이가 · 친구의 집은 · 형 나이는」)가 있고 그 뒤 1인칭 주어가 다시 안 나옴
  - 스팬 바로 뒤가 사람(「[아홉 살] 아들」 「[편의점 알바] 언니」 「[동탄에] 사는 친구」) — 나이·지명·직업·소득만
  - 예외 → self: 1인칭 소유가 스팬까지 이어짐(「친구가 내 나이 [서른넷을]」) · 내 일·생활의 상대가 주어인 일·통근·시설·가족 단서(「사장님이 [라떼아트]에 한마디」 — 단 직업명 자체는 그 사람 것) · 관계 단서(「[옆집] 아주머니」)
  - `unknown` 은 내지 않는다 (골드에도 드물다 — 개발 9 · blind 3)

### 개발셋과 blind 의 라벨 관례가 다르다

개발셋의 본인 명시 재현율이 낮은 이유는 대부분 **골드끼리 어긋난 곳**이다.

| 표현 | 개발셋 | blind | 계약 §4-1 |
|---|---|---|---|
| 남편 · 아내 · 영감 (SEX) | explicit 17 · implicit 17 (안에서도 갈림) | implicit 25/25 | 「오빠인 나 → sex implicit」 |
| 손주 · 며느리 · 셋째 (FAM) | explicit | implicit | 「큰애가 → family implicit」 |
| 통근 셔틀 · 학원버스 (COMMUTE) | explicit | inferential | — |

계약 예시와 blind 쪽을 따랐다. **A·C 가 개발셋 관례를 정리해야 할 항목**이다.

## 4. 검증

- `src/kopl/c1_span/test_attributes.py` — 82 tests: 유형별 level · subject 기본 · Codex 1·2차 반례 전부 고정
- Codex(gpt-6.1-sol) 검토 2회 — 1차 지적(조사 이중 제거 「작가로 → 작」 · 문장 경계 「동네」 · 1인칭 소유 · 「친구의」 · 호칭 예외 과다 · 직업명 사전 · 꾸밈말 시설) · 2차 지적(소유 범위 과다 · SNS 종결 「갔다 · 산대」 · 「ㅋㅋ」 경계 · 호칭 예외의 성별·소득 적용 · 「광진」)을 고치고 회귀 테스트로 고정. 2차 판정: 「고정값보다 구분 능력은 개선 — 한계를 표시하고 쓸 수 있다」

## 5. 한계

- **골드 경계·유형을 입력한 결과다.** 1단 예측 스팬(경계 오류·오탐 포함)에서의 정확도는 재지 않았다 — 체크포인트가 이 PC 에 없다. B 의 예측 파일(#293)이 오면 같이 잰다
- **이름 주어를 모른다** — 「민수는 [서른넷이고]」는 self. 사람 이름 인식이 필요하다
- **implicit 재현율이 낮다** (blind 0.60) — 사전 밖 직업 묘사가 inferential 로 떨어진다. 바꿔 쓰기 대상(explicit)에는 영향이 작다
- 규칙과 사전이다 — 문장 구조가 복잡하면(인용 · 겹문장 · 대명사) 틀린다. 틀릴 때는 계약 기본값(self) 쪽으로 기운다
