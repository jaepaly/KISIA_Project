# exp-010: [필수] 조치 3단계 재현 — 위험도 감소 −54~61%

## 무엇을 왜 재는가

PoC 결과 「비공개·위치태그 제거·리라이트 세 단계를 거치면 위험도가 −54~61% 감소한다」를 코퍼스 v0
표본으로 재현한다 ([D-stage2.md](../../docs/roles/D-stage2.md) §1 ④). 실제 엔진(C2 위험도 · C3 LOO)과
골드 스팬을 써서 수치 근거를 확인하고, 입출력을 C 에 넘겨 수요일 공동 검산에 쓴다.

## PoC 와 비교

선행 PoC 는 **R1 79 → 31 (−61%) · R3 82.1 → 37.8 (−54%)** 두 인물이고, 「② 활동 메타 관리가 최저점을 만들었고 리라이트 단독으로는 부족했다」고 기록돼 있다 ([plan.md](../../docs/plan.md) §2 · [glossary.md](../../docs/glossary.md)). R1 은 19편이다 — 인물당 글 수로는 본 표본(2.3편)보다 **전체 이력(평균 27편)이 PoC 에 가깝다.**

| PoC 기록 | 이 실험 | 판단 |
|---|---|---|
| 3단계 누적 −54~61% | 표본 −58.8% (중앙 −58.6%) · 전체 이력 −66.6% | **PoC 수준 이상의 하락이 재현된다.** 인물별 분포는 넓다 (표본에서 범위 안 13/99) |
| 리라이트 단독은 부족 | 단독 리라이트 표본 −15.7% · 전체 이력 −30.1% — 세 단계 중 가장 작거나 두 번째 | 재현 |
| 활동 메타 관리가 가장 효과적 | 전체 이력에서 위치태그 제거 단독 −11.3% < 비공개 −52.6% | **재현 안 됨** (아래) |

「활동 메타가 가장 효과적」이 재현되지 않는 이유 — 확인된 것과 확인 안 된 것을 나눠 적는다.

- **확인된 것**: C2 위험도는 축별 **최고 해상도**로 계산한다. 글이 많으면 본문의 위치 단서가 location 축을 이미 같은 해상도 이상으로 채우고 있어서, 위치태그를 지워도 그 축 값이 바뀌지 않는다 (전체 이력 87명 중 35명). 글이 적은 표본에서는 태그가 유일한 위치 단서인 경우가 많아, 태그 있는 인물의 위치태그 제거 효과가 −42.4% 로 비공개와 비슷하다.
- **확인 안 된 것**: PoC 의 「활동 메타」가 위치태그 외에 무엇을 포함했는지(활동 시간대 등)는 기록이 없다. 이 실험은 위치태그만 모사했고, 활동 시간대는 C2 에 대응하는 축이 없어 뺐다.

## 한계

1. **표본이 작다.** 인물당 2.3편(중앙 2편)이라 비공개 단계(k ≥ 1)가 위험도를 실제보다 많이 낮출 수 있다. 전체 이력(87명 · 인물당 평균 27편) 숫자가 더 현실적이다.
2. **교사 리라이트 라벨이 없다.** explicit 모드는 명시 단서의 condition 을 제거하는 규칙이고, 실제 문장 재작성은 아니다. 2단 리라이터(W9)로 측정하면 달라진다.
3. **라벨 출처가 섞여 있다.** 표본 골드는 C blind 라벨 159편 + 검수 골드(noise) 80편. 전체 이력 골드는 사람 검수가 10~30% 뿐이고(나머지는 교사 라벨), C 계열 18명(C01~C20 중)은 최상위 골드가 없어 뺐다.
4. **위치태그는 seed_sns 로 모사한 것이다.** 잡담 제외 글의 30% 에만 붙는다. 실제 사용자가 태그를 붙이는 비율과 다를 수 있고, 위치태그 단계의 평균 효과는 이 비율에 직접 좌우된다.
5. **PoC 와 위험도 척도가 다르다.** PoC 기준선은 약 80, 이 실험은 표본 17.7 · 전체 이력 48.3 이다. 그래서 절대값이 아니라 하락률만 비교한다.
