## 6. 한계 · 위험

- R1 목록은 원칙(§1-1)으로 뽑았지만 「일반 낱말로도 읽히는가」 「일반어가 일상어인가」는 사람이 판단했다(형태소 사전이 저장소에 없다). 도시 이름(이천 · 공주)은 오탐 근거가 있어 넣었지만 「이천 도자기」 「공주 밤」처럼 문맥 말 없이 쓴 진짜 지명은 놓친다
- 골드 손실 0 은 대부분 「골드에 그 낱말이 없다」는 뜻이다(채택 24개 중 13개는 골드 글 0편)
- R2 ③ · ④는 아기 · 아이 나이가 본인 판정을 끌던 것을 막는다. 주인이 문장에 없는 여섯 살 이하는 unknown 이라 2단 근거에서 빠진다 — 「여섯 살 같은 마음으로」처럼 비유로 쓴 본인 나이도 빠진다
- R4 의 나열 판정은 같은 줄 · 구분자 · 지명 사전만 본다. 「수도권(서울 · 인천 · 수원)에 산다」처럼 사는 곳을 나열로 쓴 문장도 unknown 이 된다
- 2단 판정은 생성 모델이라 실행마다 근거가 조금 다를 수 있다(각 1회)
- 남은 오탐(참고 · 손대지 않음): 해외 지명 · 모델이 낸 낱말 조각 · 협찬 글 업체 주소의 지명
