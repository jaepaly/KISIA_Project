# exp-001: 기존 개인정보 탐지 도구 3종 베이스라인 및 미탐 공간 관찰

## 무엇을 왜 재는가

- **배경**: 기존 개인정보(PII) 탐지 도구(정규식, Microsoft Presidio, 한국어 NER)가 한국어 블로그 글에서 나타나는 준식별자(지명, 나이, 직업, 가족 등)를 얼마나 놓치는지(미탐) 관찰한다.
- **핵심 질문**: 기존 도구들이 놓치는 한국형 준식별자 공간의 크기는 얼마이며, 왜 KoELECTRA 기반 1단 탐지기(`c1_span`)가 필요한가?
- **대응 지표**: `plan.md` §10 지표 1단 스팬 탐지 성능 및 기존 도구 대비 추가 탐지율

## 해석

1. **정규식 8종 (0.0% 탐지)**: 전화번호, 주민번호 등 고정 패턴 외의 한국어 자연어 문맥 준식별자는 1건도 탐지하지 못함.
2. **Microsoft Presidio (0.0% 탐지)**: 글로벌 PII 표준 도구 역시 한국어 생활 문맥형 단서("야탑역 자취방", "스물아홉", "수인분당선")를 일절 인식하지 못함.
3. **한국어 NER (spaCy ko_core_news_sm, 47.0% 탐지)**: '서울', '울산대공원', '망원역' 등 고유명사 지명이나 단순 수사('2년', '아침 6시 40분')는 일부 매칭하나, **나이('스물아홉'), 통근('수인분당선 막차'), 소득('연봉 7천', '포괄임금제', '전세대출 이자'), 주거 형태 등 핵심 문맥 준식별자 98건(53.0%)은 전원 미탐**.
4. **결론**: 제대로 설정된 공개 한국어 NER조차도 고유명사 외의 블로그 문맥 결합형 준식별자의 절반 이상(53.0%)을 완전히 놓치고 있음이 실측으로 입증됨. 따라서 준식별자 10종을 문맥적으로 태깅하는 한국어 특화 파인튜닝 모델(`c1_span`)의 필요성이 명확히 증명됨.
