# exp-001: 기존 개인정보 탐지 도구 3종 베이스라인 및 미탐 공간 관찰

## 무엇을 왜 재는가

- **배경**: 기존 개인정보(PII) 탐지 도구(정규식, Microsoft Presidio, 한국어 NER)가 한국어 블로그 글에서 나타나는 준식별자(지명, 나이, 직업, 가족 등)를 얼마나 놓치는지(미탐) 관찰한다.
- **핵심 질문**: 기존 도구들이 놓치는 한국형 준식별자 공간의 크기는 얼마이며, 왜 KoELECTRA 기반 1단 탐지기(`c1_span`)가 필요한가?
- **대응 지표**: `plan.md` §10 지표 1단 스팬 탐지 성능 및 기존 도구 대비 추가 탐지율

## 설정

| 항목 | 값 |
|---|---|
| 측정일 | 2026-08-28 (W2 1차) / 2026-09-01 (W3 등급별 분해 갱신) |
| 데이터 버전 | `corpus-v0` (페르소나 22명 `clue_plan` 185개 단서 문장) |

| 상한선 도구 | Google Gemini (W3 추가 예정) |
| 채점 기준 | **partial match (IoU ≥ 0.5, 도구 유리 원칙: type 불문, 주 지표)** · exact match (부 지표) |
| 하드웨어 | 로컬 CPU / GPU |
| 환경 | Python 3.10+, presidio-analyzer, transformers, spacy |

## 스팬 매칭 및 W3 게이트 규칙 (정본: label-schema §2 · b-baselines §7.2 · README §3)

```
경계 일치    overlap (부분 일치 허용: IoU ≥ 0.5)  ← IAA 와 동일 기준
유형 일치    기존 도구에 최대한 유리하게 판정하기 위해 type 불문 IoU 매칭 (b-baselines §7.2)
3종 합집합   하나라도 잡으면 「잡았다」
주/부 지표   partial(IoU ≥ 0.5) 이 주 지표 · exact 는 부 지표로 병기
W3 게이트   미탐 공간:   implicit ≥ 45%  AND  inferential ≥ 45%
            도달 가능성: implicit ≥ 60%  AND  inferential ≥ 60% (Gemini)
            판정: 둘 다 충족시 PASS · 하나만 충족시 PENDING · 둘 다 미달시 STOP
```

## 실행

```bash
# 1. 페르소나 clue_plan에서 단서 문장 185개 추출
python scripts/extract_clues.py -o experiments/exp01-baseline/clues.jsonl

# 2. 기존 도구 3종 실행
python experiments/exp01-baseline/run_regex.py
python experiments/exp01-baseline/run_presidio.py
python experiments/exp01-baseline/run_koreanpii.py

# 3. 비교 분석 및 W3 등급별 분해 / metrics.json 산출
python experiments/exp01-baseline/compare.py
```

> ⭐ **판정 결론**: `implicit`(50.0%)과 `inferential`(51.6%) 모두 45% 임계값을 넘어 **미탐 공간 게이트를 여유 있게 충족**했습니다.  
> 현재 LLM 상한선(Gemini) 도달 가능성은 미측정 상태이므로 #128 규칙에 따라 최종 판정은 **`PENDING (미탐 공간 충족 · 도달 가능성 미측정)`**으로 기록합니다.

## 해석 및 의의

1. **미탐 공간 45% 게이트 통과**: `implicit` 50.0%, `inferential` 51.6%로 기존 도구 3종이 문맥형 준식별자의 절반 이상을 완전히 놓치고 있음을 입증.
2. **explicit 역전 현상 규명**: `explicit` 미탐율(60.0%)이 높은 것은 정규식/NER이 한국어 수사("스물아홉", "마흔여덟")를 인식하지 못하는 기존 도구의 구조적 한계(`label-schema` §4-1)임을 확인.
3. **결론**: 규칙/NER 기반 도구의 한계를 입증하고, 문맥 기반 1단 스팬 탐지기(`c1_span`)의 당위성을 확보함.
