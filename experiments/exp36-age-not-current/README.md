# exp36-age-not-current: 「지금 내 나이가 아닌 나이」 — 괄호 속 남의 나이 · 과거 나이

**왜** (10/17 밤 · PM 「①부터 ㄱㄱ」): 실제 글 3편(친구가 테스트용으로 준 글 · 원문은 저장소에 넣지 않는다) 중 2편에서 1단이 **지금 내 나이가 아닌 나이**를 글쓴이 나이(AGE self · explicit)로 셌다. 명시 나이는 사람을 가장 강하게 좁히는 단서라, 틀린 나이 하나가 같은 조건 사람 수(k)를 크게 어긋나게 한다.

| 패턴 | 실제 글에서 본 꼴 (패턴 설명만) | 지금 | 바꿀 판정 |
|---|---|---|---|
| **Q1 괄호 속 남의 나이** | 「(아이돌 애칭)(14살) ♥ 나(27살)」 — 괄호 앞 사람의 나이 | self | **other** |
| **Q2 과거 나이** | 「오늘 기어코 15살의 (내 이름)로 돌아갔다」 — 학창 시절 회상 | self | **unknown** |

- Q2 는 **PM 결정(10/17)으로 unknown** 을 쓴다 — 내 나이이긴 하지만 지금 나이가 아니라 「문장만으로 (지금 나이를) 판단 불가」(계약 subject `unknown`). 엔진은 절반 가중 · 화면은 점선이다. **골드 관례와 어긋난다** — 교사 라벨 골드에 과거 나이를 self 로 단 예가 있다(「… 시작한 게 [스물셋]이었는데」). 이 실험은 그 관례를 바꾸는 제안이다
- 이 문서 · `score.py` · 판정셋은 **규칙 구현 결과를 보기 전에** 커밋한다

## 2. 판정 (사전 등록 · exp35 와 같은 틀 + 코퍼스)

A = main · R = 이 브랜치. 패턴마다:
1. H-pos 정답 비율 **≥ 0.75**
2. A 가 맞힌 반례를 R 이 틀리는 수 **≤ 1**

통과한 패턴만 남기고(패턴별 스위치), 남긴 규칙 전체로:
3. 반례 새 오답 합 ≤ 3 · R 정답 ≥ A
4. 골드 — 사람 검수 lost ≤ 1 · 전체 lost ≤ 5 (Q2 가 골드 과거 나이를 self → unknown 으로 바꾼 것도 lost 로 센다 — 관례 변경의 비용을 그대로 보인다)
5. **코퍼스 1단 전수** — R 이 바꾼 스팬을 D 가 전부 읽고 「틀리게 바꿈」 ≤ 2
6. 단위 테스트 · 최악 시간 ≤ 0.05초

- 떨어진 패턴은 판정셋을 본 뒤 다시 맞추지 않는다
