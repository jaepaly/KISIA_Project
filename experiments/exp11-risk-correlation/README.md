# exp11-risk-correlation: 위험도–LLM 추론 성공 상관 측정

## 1. 목적

C2 엔진 위험도와 교사 LLM의 개인정보 속성 추론 성공 개수가 함께 증가하는지 측정한다.

- 우리 점수: C2 `risk_total()`
- LLM 점수: 교사 LLM이 맞힌 7개 속성 개수, 0~7점
- 주 지표: Spearman 순위상관계수
- 목표: rho 0.7
- 관련 결정: #288

## 2. 측정 단위

인물별 게시글을 `created_at` 순으로 정렬한 뒤 앞에서부터 누적 윈도우를 만든다.

```text
윈도우 크기: 1, 2, 3, 5, 8, 12, 19
인물 수: 10명
전체 표본: 10명 × 7개 윈도우 = 70개

@'

## 3. 표본 분리

가중치 조정과 최종 보고가 섞이지 않도록 인물을 고정 분리했다.

- 튜닝군 5명: B08, D03, E14, B15, D21
- 보고군 5명: A14, E03, B06, B07, A10
- 각 인물의 윈도우: 1, 2, 3, 5, 8, 12, 19
- 전체 윈도우: 70개

## 4. 교사 LLM과 채점

교사 LLM에는 페르소나 정답을 제공하지 않고 공개 게시글만 입력했다. 다음 7개 속성을 추론하도록 했다.

- age
- sex
- location
- occupation
- family
- commute
- income

각 예측을 `persona.ground_truth`와 의미 기준으로 비교해 맞으면 1점, 틀리거나 기권하면 0점으로 판정했다. 윈도우별 추론 성공 점수는 0~7점이다.

지역은 정답의 상위 행정구역까지 허용하되, 복수 후보를 제시하거나 다른 지역을 선택한 경우 오답으로 처리했다. 직업·가족·통근은 정답과 모순되지 않는 의미상 동일 표현을 허용했다.

E03은 게시글상 현재 상하이 거주지만 `ground_truth.location`은 강릉으로 기록되어 있다. 주 분석은 #288 계약에 따라 강릉을 정답으로 사용하고, 상하이를 정답으로 둔 민감도 분석을 별도로 계산했다.

## 5. 결과

| 구분 | n | Spearman rho | p값 |
|---|---:|---:|---:|
| 전체 | 70 | 0.818 | 5.91e-18 |
| 튜닝군 | 35 | 0.836 | 4.11e-10 |
| 보고군 | 35 | 0.861 | 3.32e-11 |

추가 검증 결과는 다음과 같다.

- 인물별 rho 중앙값: 0.898
- 인물별 rho 범위: 0.705~1.000
- 한 명씩 제외한 LOPO rho 범위: 0.797~0.857
- 인물 내부 순열검정: p < 0.0001
- E03을 상하이 정답으로 처리한 민감도 분석:
  - 전체 rho 0.813
  - 보고군 rho 0.836

모든 분석에서 위험도와 LLM 추론 성공 점수 사이에 강한 양의 상관이 유지됐다.

## 6. 기여도 v1 결정

튜닝군과 미사용 보고군 모두 목표치 `rho >= 0.7`을 충족했고, 보고군 상관이 튜닝군보다 낮아지지 않았다. LOPO와 E03 민감도 분석에서도 결론이 유지됐다.

따라서 보고군 결과를 본 뒤 추가로 가중치를 조정하지 않고, 현재 C2 가중치를 기여도 v1로 확정한다. 이는 보고군에 대한 사후 과적합을 피하기 위한 결정이다.
