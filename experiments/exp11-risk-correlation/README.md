# exp11-risk-correlation: 위험도–LLM 추론 성공 상관 측정

## 1. 목적

C2 엔진 위험도와 교사 LLM의 개인정보 속성 추론 성공 개수가 함께
증가하는지 측정한다.

- 우리 점수: C2 `risk_total()`
- LLM 점수: 교사 LLM이 맞힌 7개 속성 개수, 0~7점
- 주 지표: Spearman 순위상관계수
- 사전 목표: rho 0.7
- 관련 결정: #288

## 2. 측정 단위와 데이터

인물별 게시글을 `created_at` 순으로 정렬한 뒤 앞에서부터 누적
윈도우를 만든다.

```text
윈도우 크기: 1, 2, 3, 5, 8, 12, 19
인물 수: 10명
전체 표본: 10명 × 7개 윈도우 = 70개
```

위험도 입력은 `data/corpus/v0/gold`의 최상위 골드 전체다. 검수 완료
라벨과 교사 라벨을 모두 포함하며 `gold/blind/`는 포함하지 않는다.

## 3. 표본 분리

가중치 조정과 최종 보고가 섞이지 않도록 인물을 고정 분리했다.

- 튜닝군 5명: B08, D03, E14, B15, D21
- 보고군 5명: A14, E03, B06, B07, A10
- 각 인물의 윈도우: 1, 2, 3, 5, 8, 12, 19
- 전체 윈도우: 70개

## 4. 교사 LLM과 채점

교사 LLM에는 페르소나 정답을 제공하지 않고 공개 게시글만 입력했다.
다음 7개 속성을 추론하도록 했다.

- age
- sex
- location
- occupation
- family
- commute
- income

각 예측을 `persona.ground_truth`와 의미 기준으로 비교해 맞으면 1점,
틀리거나 기권하면 0점으로 판정했다. 윈도우별 추론 성공 점수는
0~7점이다.

지역은 정답의 상위 행정구역까지 허용하되, 복수 후보를 제시하거나 다른
지역을 선택한 경우 오답으로 처리했다. 직업·가족·통근은 정답과
모순되지 않는 의미상 동일 표현을 허용했다.

위치는 현 거주지로 채점한다. 해외 인물 E01~E05는
`ground_truth.location`이 국내 연고지이므로, `ground_truth`의 다른
항목에서 확인되는 현 거주 도시를 정답으로 사용한다. 도시는 일치해야
하며 나라만 맞힌 경우는 오답으로 처리한다.

E03의 현 거주지는 상하이이므로 상하이를 주 분석 정답으로 사용한다.
`ground_truth.location`의 강릉을 적용한 결과는 민감도 분석으로만
계산한다.

## 6. 결과

튜닝·보고군 결과는 다음과 같다. 아래 p값은 70개 누적 묶음이
독립이라는 가정의 정규근사 값이므로 참고값이다.

| 구분 | n | Spearman rho | 정규근사 p(참고) |
|---|---:|---:|---:|
| 전체 | 70 | 0.813 | 1.20e-17 |
| 튜닝군 | 35 | 0.836 | 4.11e-10 |
| 보고군 | 35 | 0.836 | 3.95e-10 |

누적 묶음의 글 수 효과를 분리한 기준선 검증은 다음과 같다.

| 비교 | Spearman rho |
|---|---:|
| 엔진 위험도 ↔ 정답 수 | 0.813 |
| 묶음의 글 수 ↔ 정답 수 | 0.804 |
| 글 수를 통제한 엔진 위험도 ↔ 정답 수 | 0.412 |

- 같은 글 수 안에서 인물끼리:
  - w2: 0.40
  - w3: 0.60
  - w5: 0.60
  - w8: 0.33
  - w12: 0.27
  - w19: -0.18
  - 유효 윈도우 평균: 0.34
- 같은 글 수 안에서 인물 라벨만 섞은 층화 순열검정:
  `p=0.0015` (10,000회, 단측) — 주 p값
- 인물별 rho 중앙값: 0.898
- 인물별 rho 범위: 0.705~1.000
- 한 명씩 제외한 LOPO rho 범위: 0.797~0.851
- E03에 `ground_truth.location`의 강릉을 적용한 민감도 분석:
  - 전체 rho 0.818
  - 보고군 rho 0.861

> 누적 70개 묶음에서 위험도와 교사 LLM 추론 성공 수의 Spearman rho는
> 0.813으로 목표 0.7을 넘었다. 다만 묶음의 글 수만으로도 rho=0.804가
> 나와 상관의 대부분은 글이 쌓이는 효과다. 글 수를 통제하면 rho=0.41이고,
> 같은 글 수 안에서 인물을 섞는 순열검정 p=0.0015로 엔진은 글 수 이상의
> 정보를 준다.

### 6-1. B 모델 예측 민감도 분석 (#293)

위험도 입력의 교사 라벨과 추론 성공을 측정한 교사 LLM이 같은 Claude
계열이라는 순환 가능성을 확인하기 위해, 같은 190편을 B의 등록 v1 예측
2종으로 교체해 위험도를 다시 계산했다. 예측 파일에는
`text_id`·`start`·`end`·`type`만 있으며, `level`·`subject`는 #306의
`resolve()` 규칙으로 판정했다.

- v1: 등록 v1, 임계값 0.7
- v1+규칙: 같은 v1 후보에 명시 규칙을 병합
- 표본·윈도우·교사 LLM 성공 점수는 본 분석과 동일
- 원본 교사 라벨 결과는 덮어쓰지 않고 별도 산출물로 저장

| 위험도 입력 | 전체 rho | 튜닝군 rho | 보고군 rho | 글 수 통제 부분상관 | 층화 순열 p |
|---|---:|---:|---:|---:|---:|
| 골드·교사 라벨 | 0.813 | 0.836 | 0.836 | 0.412 | 0.0015 |
| B v1 | 0.764 | 0.812 | 0.769 | 0.254 | 0.0527 |
| B v1+규칙 | 0.795 | 0.807 | 0.831 | 0.331 | 0.0099 |

글 수 기준선은 세 분석 모두 `rho=0.804`로 같았다. 실제 B 예측으로
바꾸면 전체 상관은 `0.813`에서 `0.764`로 낮아져 교사 라벨 사용에 따른
일부 상승 효과가 확인됐다. 규칙을 병합하면 전체 `0.795`, 보고군
`0.831`로 회복했고, 같은 글 수 안에서 인물을 섞은 검정도
`p=0.0099`였다. 따라서 본 분석의 상관은 교사 순환만으로 생긴 결과는
아니지만, 글 수를 제외한 추가 설명력은 골드 입력보다 낮다.

안정성 결과는 다음과 같다.

| 위험도 입력 | 인물별 rho 중앙값 | 인물별 범위 | LOPO rho 범위 |
|---|---:|---:|---:|
| B v1 | 0.882 | 0.841~1.000 | 0.735~0.781 |
| B v1+규칙 | 0.901 | 0.849~1.000 | 0.763~0.821 |

같은 글 수 안에서 인물끼리 비교한 rho는 다음과 같다.

| 입력 | w1 | w2 | w3 | w5 | w8 | w12 | w19 |
|---|---:|---:|---:|---:|---:|---:|---:|
| B v1 | -0.25 | 0.38 | 0.28 | 0.68 | -0.26 | -0.02 | -0.13 |
| B v1+규칙 | -0.25 | 0.38 | 0.28 | 0.70 | 0.33 | 0.04 | -0.05 |

규칙 병합은 특히 w8에서 인물 간 순위를 개선했지만, w19는 두 입력 모두
음수다. 전체 이력 시점의 인물 간 위험 순위는 여전히 확인되지 않았다.

## 7. 기여도 v1 결정

가중치는 `model.py`의 기본값인 전 축 1.0에서 조정하지 않았다. 보고군
결과를 본 뒤에도 바꾸지 않았다. 다만 글 수 기준선이 0.80이므로 이
측정만으로 가중치의 우열은 가리지 못한다. 가중치 비교는 이후 과제로
둔다.

## 8. 한계

- C2 엔진은 국내 행정구역만 다루므로 해외 거주지를 위치 축에 반영하지
  못한다. E03은 교사 LLM이 상하이를 맞혀도 엔진 위험도에는 반영되지
  않을 수 있다.
- 전체 이력인 w19에서 인물 간 순위상관은 -0.18이다. 게시글이 19편까지
  쌓였을 때 인물 간 위험 순위를 맞히는 성능은 확인되지 않았다.
- B 모델 예측 민감도에서 전체 rho가 0.813에서 0.764로 낮아져 교사
  라벨 사용에 따른 일부 상승 효과가 확인됐다. v1+규칙은 0.795까지
  회복했지만 글 수 통제 부분상관은 골드 0.412보다 낮은 0.331이다.
- 같은 글 수의 인물 간 rho는 윈도우에 따라 변동이 크고, w19에서는
  v1 -0.13, v1+규칙 -0.05로 음수다.

윈도우 입력 생성:


```powershell
python experiments/exp11-risk-correlation/run_teacher.py `
  --all `
  --dry-run
```

교사 LLM 70개 실행:

```powershell
python experiments/exp11-risk-correlation/run_teacher.py `
  --all `
  --env-file C:\secure\kisia-gateway.env `
  --model claude-sonnet-4-6
```

`teacher_all.jsonl`의 속성별 추론값을 규칙에 따라 검산해
`results/teacher_all_scored.csv`를 만든다. 이 파일이 커밋된 재현
입력이다.

```powershell
python experiments/exp11-risk-correlation/score.py `
  --scored experiments/exp11-risk-correlation/results/teacher_all_scored.csv
```
