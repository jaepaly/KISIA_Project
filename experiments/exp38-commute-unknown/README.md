# exp38-commute-unknown: 교통 말이 없는 COMMUTE 는 버리지 않고 unknown(점선)으로 낮춘다

**왜** (10/18 · PM 「ㄱㄱ」): exp37 F2(교통 말 없는 COMMUTE 버리기)는 조각을 0.93 잡았지만 목록 밖 단서(「지옥철 · 출장 · 드라이브 · 비행기」)를 13개 잘못 **버렸다**. 버리면 틀렸을 때 단서가 사라진다. **unknown 으로 낮추면** 틀려도 화면에 점선으로 남고 엔진은 절반 가중으로 센다(#381 · 계약 subject `unknown` = 문장만으로 판단 불가) — 잘못 낮춘 비용이 작다.

이 문서 · `score.py` · 규칙(§1) · 판정셋 1단 결과는 **판정셋 라벨을 보기 전에** 커밋한다.
