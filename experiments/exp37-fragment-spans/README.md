# exp37-fragment-spans: 1단이 잡은 「조각」 스팬 버리기 — 조사 조각 · 교통 말 없는 COMMUTE

**왜** (10/18 · PM 「ㄱ」 — 친구 글 반복 오탐 ② 「통근이 아닌 이동」): 실제 글에서 1단이 「오늘」 「갔다가」 「시내 나가서」를 COMMUTE(통근 단서)로 칠했다. 서버 실모델에 합성 탐침 문장을 넣어 보니 같은 꼴이 재현됐다. 코퍼스 1단 결과(exp30 ~ 32 에서 받아 둔 test 밖 2,481편)의 COMMUTE 스팬 263개를 보니 **40개(15%)가 교통 · 통근과 무관한 조각**이었다 — 「의」 「에」 「서」 「낡은」 「아침」 「가는」 「요즘」. 골드가 있는 31개는 **하나도 골드와 맞지 않았다**. 다른 유형에도 조사 하나만 잡힌 스팬이 있다(「의」 「에서」 — JOB · 시설 · FAM 등 72개 중 골드 일치 2개는 한 글자 호칭).

화면에서 이런 조각이 단서로 칠해지면 사용자는 도구가 망가졌다고 느낀다. k 계산에서도 COMMUTE inferential 이 하나 늘어난다.

**범위 밖 (PM 보고)**: 「버스타서 시내 나갔다」의 「버스타서」 자체는 남긴다. 골드 관례는 통근이 아니어도 교통수단(「시내버스에서 졸았다」)을 COMMUTE self 로 단다 — 이걸 바꾸는 건 관례 변경이라 이 실험에서 하지 않는다. 「옆집 고양이」의 「옆집」(REL_HOME self)도 관례상 맞다(내 집 기준 관계어).

이 문서 · `score.py` · 규칙 정의(§1)는 **판정셋 라벨을 보기 전에** 커밋한다.

## 1. 규칙 (커밋 시점에 고정)

`src/kopl/c1_span/rules.py` 의 `merge_with_model` 이 **모델 후보**를 받을 때(기존 「서른 해 동안」 · 「노을맛집」 버림과 같은 자리) 아래에 걸리면 버린다. 규칙 후보(명시 정규식)는 건드리지 않는다.

- **F1 조사 조각 (모든 유형)**: 앞뒤 공백을 뺀 스팬 글자가 아래 목록 중 하나와 **통째로** 같다
  `의 에 에서 에서도 에는 에게 서 서는 로 으로 고 다 데 대 시 가 이 은 는 을 를 도 만 와 과 랑 하고 까지 부터 요 죠 첫`
- **F2 교통 말 없는 COMMUTE**: 유형이 COMMUTE 이고 스팬 글자에 아래 정규식이 **한 번도** 걸리지 않는다
  ```
  버스|차|지하철|전철|철도|열차|기차|KTX|SRT|호선|[가-힣]선(?![가-힣])|역|정류장|정거장|환승|셔틀|택시|자전거|오토바이|
  트럭|포터|승합|카풀|운전|몰고|시동|주차|워셔액|경유|기름값|주유|걸어서|도보|걷|출근|퇴근|통근|통학|등교|하교|등굣|
  재택|야근|야간|노선|막차|첫차|편도|분이|시간표|놓치|\d+\s*번|[일이삼사오육칠팔구십백]+\s*분
  ```
- 판정 함수는 `is_fragment_span(kind, text) -> bool` (스위치를 따른다) · 패턴별 스위치 `_DROP_F1 · _DROP_F2` · 버린 수는 통계 `model_fragment_dropped`

규칙은 **개발 자료**(코퍼스 1단 2,481편 · 골드 COMMUTE 174개)만 보고 만들었다. 골드 COMMUTE 174개 중 F2 에 걸리는 것은 0개(목록에 「야간 · 놓치」를 넣어 맞췄다).
